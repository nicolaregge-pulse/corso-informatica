Il Modulo Google

Qui l'allievo apre il Modulo Google della lezione: il Feedback sulla teoria oppure la «Consegna» con la sua Pull Request (Titolo, Cosa cambia, Dove, Perché). Appena preme «Invia», lo script porta la risposta su Git entro un minuto e la PR compare nel backlog. Nella demo il Modulo vero non si apre, per non mescolare le prove con le consegne della classe.
