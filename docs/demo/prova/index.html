FASE 1 — La teoria. Come lavorano le aziende di software: ogni modifica è una versione; chi vuole cambiare qualcosa manda una Pull Request (richiesta di modifica) con titolo, cosa cambia, dove e perché; le richieste aspettano nel backlog; quelle accettate entrano nel prodotto. È il metodo Agile: piccoli passi, sbagliare presto, correggere presto.
