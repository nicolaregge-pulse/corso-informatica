Calcolatrice su GitHub: la strada facile

Solo 3 passi. Prima salva in Lazarus con Ctrl + S.

1 · Scrivi il tuo nome di GitHub

È il nome che vedi nell'indirizzo del tuo repository: github.com/nome/lazarus

2 · Trascina i 4 file su GitHub

  1. Clicca il bottone verde: si apre GitHub già nella cartella «calcolatrice».
    Apri GitHub nella cartella calcolatrice
  2. Apri Esplora file, nella cartella dove hai salvato la calcolatrice.
  3. Prendi solo questi 4 file (tieni premuto Ctrl e clicca uno alla volta):
    calcolatrice.lpicalcolatrice.lprunit1.pasunit1.lfm
    NON prendere: .exe, .lps, .res, le cartelle lib e backup.
  4. Trascinali con il mouse dentro il riquadro grande della pagina di GitHub.
  5. In basso clicca il bottone verde Commit changes.

Non vedi «.lpi», «.pas»…? In Esplora file clicca in alto «Visualizza», poi «Mostra», poi «Estensioni nomi file».

3 · Ogni volta che una cosa nuova funziona

  1. In Lazarus premi Ctrl + S.
  2. Clicca di nuovo il bottone verde «Apri GitHub nella cartella calcolatrice».
  3. Trascina di nuovo i 4 file e clicca Commit changes.

Fatto 3 volte? Premi «Controlla».
