La Pull Request in coppia

Siete in due. A è il padrone del sito. B è il compagno che propone una modifica. Fate i passi in ordine; quando avete finito, vi scambiate i ruoli.

A · padrone del sito

1. Invita il compagno

  1. Apri il tuo repository su GitHub (quello del tuo sito).
  2. In alto, nella riga dei menu, clicca ⚙ Settings (l'ultima voce a destra; se non la vedi, è dentro i tre puntini «…»).
  3. Nel menu a sinistra clicca Collaborators. Se GitHub chiede la password, scrivila.
  4. Clicca il bottone verde Add people.
  5. Scrivi il nome utente GitHub di B, sceglilo dall'elenco e clicca il bottone verde per aggiungerlo.
Fatto quando vedi B nell'elenco con la scritta «Pending invite» (invito in attesa).
B · compagno

2. Accetta l'invito

  1. Scrivi qui sotto nome utente e repository di A: il bottone ti porta dritto all'invito.

Apri l'invito di A

  1. Nella pagina che si apre clicca il bottone verde Accept invitation (accetta l'invito).

Altro modo: l'invito arriva anche nella tua email della scuola («invited you to collaborate») e nella campanella di GitHub in alto a destra.

Fatto quando si apre il repository di A: adesso puoi modificarlo.
B · compagno

3. Proponi la modifica (la Pull Request)

  1. Nel repository di A clicca il file index.html.
  2. In alto a destra, sopra il codice, clicca la matita ✏️.
  3. Scendi in fondo al file. Prima di </main> (se non c'è, prima del <footer> o di </body>) clicca all'inizio della riga, premi Invio e nella riga vuota aggiungi la tua sezione, per esempio:
    <h2>Il mio compagno di lavoro</h2><p>Tre righe su A e un consiglio per il suo sito.</p>
  4. In alto a destra clicca il bottone verde Commit changes…
  5. Nella finestra che si apre scegli il pallino «Create a new branch for this commit and start a pull request» (crea un ramo nuovo e apri una Pull Request).
  6. Clicca Propose changes.
  7. Nella pagina «Open a pull request» clicca il bottone verde Create pull request.
Fatto quando vedi la tua Pull Request con il pallino verde «Open».
A · padrone del sito

4. Accetta la Pull Request (merge)

  1. Nel tuo repository, in alto, clicca la scheda Pull requests (accanto a «Issues»): c'è un numero, per esempio 1.
  2. Clicca il titolo della Pull Request di B.
  3. Se vuoi vedere che cosa ha cambiato, clicca la scheda Files changed: in verde le righe aggiunte.
  4. Torna alla scheda Conversation e scendi in fondo.
  5. Clicca il bottone verde Merge pull request (unisci).
  6. Clicca il bottone verde Confirm merge (conferma).
Fatto quando compare l'etichetta viola «Merged». La sezione di B adesso è nel tuo sito!
A · padrone del sito

5. Il numero di versione

  1. Apri index.html, matita, e nel piè di pagina scrivi <footer>Versione 1.1</footer> (era 1.0: una Pull Request accettata fa salire il secondo numero).
  2. Commit changes… → questa volta lascia «Commit directly to the main branch» → Commit changes.

6. Scambio dei ruoli

Adesso B diventa padrone del suo sito e A è il compagno: rifate i passi da 1 a 5.

Bloccati? Scrivete nella casella «Chiedi aiuto all'assistente» qui sotto, con il passo a cui siete fermi.
