## 4. Parole da ricordare

| Parola | Che cosa vuol dire |
|---|---|
| **repository** | la cartella del progetto su GitHub |
| **ramo (branch)** | una copia del progetto dove lavori senza rompere l'originale |
| **Pull Request** | la richiesta di unire le tue modifiche al progetto |
| **client e server** | il client chiede, il server risponde |
| **protocollo** | le regole con cui due programmi si scrivono |
| **release** | una versione del programma con un numero, pronta da usare |
