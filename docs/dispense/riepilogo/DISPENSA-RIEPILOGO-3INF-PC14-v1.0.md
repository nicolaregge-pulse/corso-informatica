## 4. Parole da ricordare

| Parola | Che cosa vuol dire |
|---|---|
| **repository** | la cartella del progetto su GitHub · GitHub-এ প্রজেক্টের ফোল্ডার |
| **ramo (branch)** | una copia del progetto dove lavori senza rompere l'originale · প্রজেক্টের একটি কপি, যেখানে মূলটি নষ্ট না করে কাজ করা যায় |
| **Pull Request** | la richiesta di unire le tue modifiche al progetto · তোমার পরিবর্তন প্রজেক্টে যুক্ত করার অনুরোধ |
| **client e server** | il client chiede, il server risponde · ক্লায়েন্ট চায়, সার্ভার উত্তর দেয় |
| **protocollo** | le regole con cui due programmi si scrivono · যে নিয়মে দুটি প্রোগ্রাম একে অপরকে বার্তা পাঠায় |
| **release** | una versione del programma con un numero, pronta da usare · নম্বরসহ প্রোগ্রামের একটি সংস্করণ, ব্যবহারের জন্য তৈরি |
