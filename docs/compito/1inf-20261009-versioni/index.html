Le versioni del nostro treno

1INF · 09/10/2026

1 Teoria (proposta da approvare)

1. Una versione è un salvataggio del gioco. Ha un numero: v1.0.

النسخة هي حفظ للعبة. لها رقم: v1.0.

版本就是游戏的一次保存。它有一个号码：v1.0。

2. Cambia una cosa piccola: cresce il numero dopo il punto. v1.0 → v1.1

تغيير صغير: يكبر الرقم بعد النقطة. v1.0 ← v1.1

小的改变：点后面的数字变大。v1.0 → v1.1

3. Cambia una cosa grande: cresce il primo numero. v1.1 → v2.0

تغيير كبير: يكبر الرقم الأول. v1.1 ← v2.0

大的改变：第一个数字变大。v1.1 → v2.0

4. Una proposta è un'idea per il gioco. Il prof dice SÌ (entra nel gioco) o NO.

الاقتراح فكرة للعبة. الأستاذ يقول نعم (تدخل اللعبة) أو لا.

建议就是给游戏的一个想法。老师说"是"（加入游戏）或"不"。

2 Compito

Da costruire insieme, dopo che la teoria è approvata.
