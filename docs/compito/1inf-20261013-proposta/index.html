Passo 4 · La Pull Request

Una Pull Request è una proposta: «cambia questa riga così».

Pull Request هو اقتراح: «غيّر هذا السطر هكذا».

Pull Request 就是一个建议：「把这一行改成这样」。

Il prof legge. SÌ: la tua idea entra nel gioco e nasce una versione nuova. NO: la puoi correggere e mandare di nuovo.

الأستاذ يقرأ. نعم: فكرتك تدخل اللعبة وتولد نسخة جديدة. لا: يمكنك تصحيحها وإرسالها من جديد.

老师会读。是：你的想法加入游戏，产生一个新版本。不：你可以修改后再发一次。

Una Pull Request ha 3 parti · لها 3 أجزاء · 它有3个部分

1. La riga
1. السطر
1. 哪一行

Passo 5 · Manda la tua Pull Request

  1. Premi il bottone verde: si apre il Modulo «Consegna».
    اضغط الزر الأخضر: يفتح النموذج «Consegna» (التسليم).
    按绿色按钮：会打开表格「Consegna」（提交）。
    Scrivi la tua Pull Request
  2. Nella prima casella scrivi esattamente così:
    في الخانة الأولى اكتب هذه الكلمات بالحروف اللاتينية، تماماً هكذا:
    在第一个格子里，用拉丁字母完全照这样写：

    pull request

  3. Nella seconda casella scrivi le 3 parti: la riga, il valore nuovo, perché. Puoi scrivere nella tua lingua.
    في الخانة الثانية اكتب الأجزاء الثلاثة: السطر، القيمة الجديدة، لماذا. يمكنك الكتابة بلغتك.
    在第二个格子里写3个部分：哪一行、新的值、为什么。你可以用你的语言写。
  4. In fondo al Modulo premi il bottone viola «Invia».
    في أسفل النموذج اضغط الزر البنفسجي «Invia» (إرسال).
    在表格最下面按紫色按钮「Invia」（发送）。
  5. Hai un'altra idea? Premi di nuovo il bottone verde.
    عندك فكرة أخرى؟ اضغط الزر الأخضر مرة أخرى.
    还有别的想法？再按一次绿色按钮。

Quando la tua idea entra nel gioco, la vedi in «Cosa è cambiato oggi nel gioco», il bottone giallo in alto.

عندما تدخل فكرتك اللعبة، تراها في «ما الجديد في اللعبة»، الزر الأصفر في الأعلى.

当你的想法加入游戏时，你可以在上面黄色的按钮「游戏里的新变化」里看到。
