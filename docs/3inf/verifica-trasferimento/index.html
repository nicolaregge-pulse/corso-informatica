Questa pagina guarda se i repository degli allievi sono nell'organizzazione e se i loro siti si aprono. Premi il bottone: i dati si leggono da GitHub in questo momento.

Da sapere. Il piano gratuito mostra le Pages solo per repository pubblici, e senza accesso la pagina vede solo i repository pubblici: un repository privato non compare, e quell'allievo risulta «Non ancora passato». GitHub lascia 60 richieste all'ora senza accesso: ogni controllo ne usa poche, perché legge l'ultimo commit solo dei repository cambiati. Il nuovo indirizzo di ogni sito è . GitHub non accetta il trasferimento se nell'organizzazione c'è già un repository con lo stesso nome: per questo ogni allievo prima cambia il nome in mio-sito-COGNOME.
