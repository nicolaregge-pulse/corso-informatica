La calcolatrice su GitHub

Un passo alla volta. Ogni passo si apre solo quando quello prima è giusto: la pagina controlla da sola il tuo GitHub.

Passo 1 di 7

Prima di tutto: due posti diversi

Il PC e GitHub non si aggiornano da soli: sei tu a portare i file dal PC a GitHub. Prima salvi sul PC, poi fai il commit.

Passo 1 · Il tuo nome su GitHub

  1. Scrivi qui il tuo nome utente di GitHub (quello che vedi in alto a destra su github.com, o nell'indirizzo del tuo repository).

Passo 2 · Salva la calcolatrice sul tuo PC

  1. In Lazarus clicca il menu «File», poi «Salva progetto con nome».
  2. Crea una cartella nuova che si chiama calcolatrice e salva lì dentro.
  3. Come nome del progetto scrivi calcolatrice e premi «Salva». Poi salva anche unit1 nella stessa cartella.
  4. Da adesso, ogni pochi minuti premi Ctrl + S.
  5. Apri Esplora file, la cartella calcolatrice. In alto clicca «Visualizza», «Mostra», e metti la spunta su «Estensioni nomi file». Ora vedi calcolatrice.lpi, unit1.pas…

Questo passo è sul tuo PC: la pagina non lo può vedere. Premi il bottone solo quando vedi i file con le estensioni.

Passo 3 · Crea la cartella «calcolatrice» su GitHub

  1. Apri il tuo repository lazarus su GitHub.
  2. Clicca il bottone «Add file», poi «Create new file».
  3. Nella casella del nome scrivi esattamente: calcolatrice/README.md (la barra / crea la cartella).
  4. Nel riquadro grande scrivi una riga: La mia calcolatrice in Lazarus
  5. Clicca il bottone verde «Commit changes», poi ancora «Commit changes».

Passo 4 · La prima volta: carica SOLO i 4 file giusti

  1. Su GitHub clicca la cartella calcolatrice.
  2. Clicca «Add file», poi «Upload files».
  3. Clicca «choose your files»: si apre la finestra del PC.
  4. Apri la cartella calcolatrice e scegli solo questi 4 file, tenendo premuto Ctrl: calcolatrice.lpi, calcolatrice.lpr, unit1.pas, unit1.lfm.
  5. Clicca «Apri».
  6. Nella casella sotto scrivi: prima versione
  7. Clicca il bottone verde «Commit changes».

NON caricare: .exe, .lps, .res, e le cartelle lib e backup. Lazarus li rifà da solo.

Passo 5 · Fai un commit quando una cosa nuova funziona

  1. In Lazarus aggiungi o cambia qualcosa (per esempio il bottone per) e provalo con «Esegui».
  2. Funziona? Premi Ctrl + S: hai salvato sul PC.
  3. Su GitHub clicca la cartella calcolatrice, poi «Add file», «Upload files».
  4. Clicca «choose your files» e scegli di nuovo i 4 file con Ctrl. Clicca «Apri»: GitHub mette i nuovi al posto dei vecchi.
  5. Nella casella scrivi che cosa hai cambiato, per esempio: aggiunto il bottone per
  6. Clicca il bottone verde «Commit changes».

Regola facile: ha funzionato? Commit. Più commit fai, più la storia del tuo progetto è chiara.

Passo 6 · La release v1.0: la versione da mostrare

  1. Nella pagina principale del repository lazarus, nella colonna a destra, clicca «Releases» (oppure «Create a new release»).
  2. Clicca «Choose a tag», scrivi v1.0 e clicca «Create new tag».
  3. Nel titolo scrivi: Calcolatrice versione 1
  4. Clicca il bottone verde «Publish release».

Passo 7 · Sai spiegarlo?

  1. Che differenza c'è tra salvare con Ctrl + S e fare un commit?
  2. Perché su GitHub non mettiamo il file .exe?
  3. Che cos'è la release v1.0?

Rispondi a voce al tuo compagno di banco. Poi aspetta il prof: con la versione 2 aggiungiamo meno e divisione, e farai la release v2.0.

Bravo! Il tuo progetto è al sicuro su GitHub e ha la sua prima versione.
