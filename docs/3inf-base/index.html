Il mio primo sito: due file

Un passo alla volta. Ogni bottone verde copia il testo giusto.

1index.html

Premi il bottone verde.

Su GitHub apri index.html, clicca la matita ✏️ (in alto a destra, sopra il codice), clicca nel riquadro vuoto e premi Ctrl + V. Poi il bottone verde Commit changes e ancora Commit changes.

2style.css

Premi il bottone verde.

Su GitHub apri style.css, clicca la matita ✏️, clicca nel riquadro vuoto e premi Ctrl + V. Poi Commit changes e ancora Commit changes.

3Fallo tuo

Apri di nuovo index.html con la matita e cambia la frase «Scrivi qui chi sei» con una frase tua. Commit changes. Bravo: il sito è tuo!

<!DOCTYPE html>
<html lang="it">
<head>
<meta charset="utf-8">
<title>Il mio sito</title>
<link rel="stylesheet" href="style.css">
</head>
<body>
<header>
<h1>Ciao, sono io</h1>
<nav><a href="index.html">Home</a> <a href="competenze.html">Competenze</a> <a href="passione.html">La mia passione</a></nav>
</header>
<main>
<p>Scrivi qui chi sei, con parole tue.</p>
</main>
<footer>Versione 1.0</footer>
</body>
</html>
