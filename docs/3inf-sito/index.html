PUBBLICARE: i passi giusti (leggi qui se ti blocchi)

  1. Nel tuo repository mio-sito clic su Settings (ingranaggio, ultima scheda in alto a destra). Non la vedi? Clic su More ▾ tutto a destra.
  2. Nel menu a sinistra clic su Pages.
  3. Sotto Branch clic su None → scegli main → Save.
  4. Custom domain: NON scrivere niente. Non serve, non si paga niente.
  5. Aspetta 2 minuti, premi F5: in alto Your site is live → Visit site. Indirizzo: https://TUONOME.github.io/mio-sito/

Settings → Pages → Branch: main → Save. Custom domain: কিছুই লিখবে না, খালি রাখো। ২ মিনিট পরে F5 → Visit site।

SOTTOPAGINE: aggiungi 2 pagine al tuo sito

Per chi ha già il sito online. Tutto su GitHub, dal browser. Il tuo sito avrà un menu: Home | Le mie passioni | Il mio sogno.

  1. Nel tuo repository: Add file → Create new file. Nome del file: passioni.html. Incolla il RIQUADRO A. Bottone verde Commit changes (2 volte).
  2. Di nuovo Add file → Create new file. Nome: sogno.html. Incolla il RIQUADRO B. Commit changes.
  3. Apri index.html → matita. Subito sotto la riga <body> incolla il RIQUADRO C (il menu). Commit changes.
  4. Aspetta 1 minuto, apri il tuo sito, Ctrl + F5: clicca il menu e passa da una pagina all'altra. FATTO!
  5. Fallo tuo: con la matita cambia i testi delle 2 pagine con le TUE passioni e il TUO sogno.

Add file → Create new file → passioni.html (বাক্স A) ও sogno.html (বাক্স B) → Commit changes। index.html-এ <body>-এর নিচে বাক্স C (মেনু) → Commit changes। ১ মিনিট পরে সাইটে Ctrl + F5।
