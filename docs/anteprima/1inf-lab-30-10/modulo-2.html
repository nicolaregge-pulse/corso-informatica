Ripasso in 1 minuto. Una String è testo: sta tra apici, 'Ciao'. Il + attacca due String: 'Ciao ' + 'Ahmed' = 'Ciao Ahmed'. Quello che l'utente scrive in Edit1 si legge con Edit1.Text, ed è sempre una String. Una variabile è una scatola con un nome: var nome: String; prepara la scatola nome per il testo.

مراجعة في دقيقة. String هي نص: بين علامتي اقتباس 'Ciao'. علامة + تلصق نصين: 'Ciao ' + 'Ahmed' = 'Ciao Ahmed'. ما يكتبه المستخدم في Edit1 يُقرأ بـ Edit1.Text وهو دائماً String. المتغير صندوق له اسم: var nome: String; يجهّز الصندوق nome للنص.

1 分钟复习。String 是文字：放在单引号里 'Ciao'。+ 把两个 String 连起来：'Ciao ' + 'Ahmed' = 'Ciao Ahmed'。用户在 Edit1 里写的东西用 Edit1.Text 读取，它永远是 String。变量是一个有名字的盒子：var nome: String; 准备一个叫 nome 的盒子装文字。

12La trappola degli apici

فخ علامات الاقتباس

引号的陷阱

Chiudi il programma. Nell'ultima riga metti gli apici intorno a nome: 'nome'. Premi F9 e prova: compare nome detto Leone! Perché? Con gli apici è la PAROLA nome, senza apici è la SCATOLA nome. Togli gli apici.

أغلق البرنامج. في السطر الأخير ضع علامتي اقتباس حول nome: 'nome'. اضغط F9 وجرّب: يظهر nome detto Leone! لماذا؟ مع علامات الاقتباس هي الكلمة nome، وبدونها هي الصندوق nome. أزل علامات الاقتباس.

关掉程序。在最后一行给 nome 加上引号：'nome'。按 F9 试试：出现 nome detto Leone！为什么？有引号是“nome”这个词，没有引号是叫 nome 的盒子。把引号去掉。

  Label1.Caption := 'nome' + ' detto ' + animale + '!';

Sei bloccato? Tre aiuti, uno alla volta · ثلاث مساعدات · 三个提示

Aiuto 1: un indizio

Le righe var vanno PRIMA di begin. Le scatole si riempiono con :=. Le parole fisse vanno tra apici, le scatole no.

أسطر var تأتي قبل begin. الصناديق تُملأ بـ :=. الكلمات الثابتة بين علامات اقتباس، والصناديق لا.

var 那几行写在 begin 前面。盒子用 := 装东西。固定的字放在引号里，盒子不用。

Aiuto 2: il pezzo di codice
procedure TForm1.Button1Click(Sender: TObject);
var
  nome: String;
  animale: String;
begin
  nome := Edit1.Text;
  animale := Edit2.Text;
  Label1.Caption := nome + ' detto ' + animale + '!';
end;
Aiuto 3: tutto unit1.pas

Non copiare tutto: le righe in alto le scrive Lazarus da solo quando metti i pezzi nella Form. Tu scrivi solo le righe dentro le procedure.

لا تنسخ كل شيء: الأسطر في الأعلى يكتبها Lazarus وحده عندما تضع القطع في الـ Form. أنت تكتب فقط الأسطر داخل الإجراءات.

不要全部照抄：上面那些行是你往 Form 里放组件时 Lazarus 自己写的。你只写过程里面的那几行。

unit Unit1;

{$mode objfpc}{$H+}

interface

uses
  Classes, SysUtils, Forms, Controls, Graphics, Dialogs, StdCtrls;

type

  { TForm1 }

  TForm1 = class(TForm)
    Button1: TButton;
    Button2: TButton;
    Edit1: TEdit;
    Edit2: TEdit;
    Label1: TLabel;
    procedure Button1Click(Sender: TObject);
    procedure Button2Click(Sender: TObject);
  private

  public

  end;

var
  Form1: TForm1;

implementation

{$R *.lfm}

{ TForm1 }

procedure TForm1.Button1Click(Sender: TObject);
var
  nome: String;
  animale: String;
begin
  nome := Edit1.Text;
  animale := Edit2.Text;
  Label1.Caption := nome + ' detto ' + animale + '!';
end;

procedure TForm1.Button2Click(Sender: TObject);
begin
  Edit1.Text := '';
  Edit2.Text := '';
  Label1.Caption := '...';
end;

end.
