Che cosa fai in quest'ora

Tutta l'ora parla di String e Integer. Prima mezz'ora: la teoria in 6 schede, con una domanda dopo ogni scheda, e il quiz. Poi un programma piccolo che mostra la differenza: il bottone Testo fa '5' + '3' e compare 53; il bottone Numeri fa 5 + 3 con due Integer e compare 8.

الساعة كلها عن String و Integer. النصف ساعة الأولى: النظرية في 6 بطاقات، مع سؤال بعد كل بطاقة، ثم الاختبار. بعدها برنامج صغير يُظهر الفرق: الزر Testo يفعل '5' + '3' فيظهر 53؛ والزر Numeri يفعل 5 + 3 بعددين Integer فيظهر 8.

这一节课都讲 String 和 Integer。前半小时：6 张理论卡片，每张后面一个问题，然后做测验。之后写一个小程序来看区别：Testo 按钮做 '5' + '3'，出现 53；Numeri 按钮用两个 Integer 做 5 + 3，出现 8。

Aiuto 1: un indizio

Testo: i numeri tra apici sono String e il + li attacca. Numeri: le righe var vanno prima di begin; la Caption vuole una String, quindi IntToStr(a + b).

Testo: الأرقام بين علامات اقتباس هي String والـ + يلصقها. Numeri: أسطر var قبل begin؛ الـ Caption تريد String، لذلك IntToStr(a + b).

Testo：引号里的数字是 String，+ 把它们连起来。Numeri：var 那几行写在 begin 前面；Caption 要 String，所以写 IntToStr(a + b)。

Aiuto 3: tutto unit1.pas

Non copiare tutto: le righe in alto le scrive Lazarus da solo quando metti i pezzi nella Form. Tu scrivi solo le righe dentro le procedure.

لا تنسخ كل شيء: الأسطر في الأعلى يكتبها Lazarus وحده عندما تضع القطع في الـ Form. أنت تكتب فقط الأسطر داخل الإجراءات.

interface

  { TForm1 }

    Button1: TButton;
    Button2: TButton;
    Label1: TLabel;
    procedure Button1Click(Sender: TObject);
    procedure Button2Click(Sender: TObject);
  private

  public

  end;

var
  Form1: TForm1;

implementation

{$R *.lfm}

{ TForm1 }

procedure TForm1.Button1Click(Sender: TObject);
begin
  Label1.Caption := '5' + '3';
end;

procedure TForm1.Button2Click(Sender: TObject);
var
  a, b: Integer;
begin
  a := 5;
  b := 3;
