Sei bloccato? Tre aiuti, uno alla volta · ثلاث مساعدات · 三个提示

Aiuto 1: un indizio

Ogni riga va tra begin e end; e finisce con ;. La scritta va tra apici: 'APERTO'. Il colore comincia con cl.

كل سطر يوضع بين begin و end; وينتهي بـ ;. الكتابة توضع بين علامتي اقتباس: 'APERTO'. اللون يبدأ بـ cl.

每一行都写在 begin 和 end; 之间，以 ; 结尾。文字放在单引号里：'APERTO'。颜色以 cl 开头。

Aiuto 2: il pezzo di codice
procedure TForm1.Button1Click(Sender: TObject);
begin
  Label1.Caption := 'APERTO';
  Label1.Font.Color := clGreen;
end;
Aiuto 3: tutto unit1.pas

Non copiare tutto: le righe in alto le scrive Lazarus da solo quando metti i pezzi nella Form. Tu scrivi solo le righe dentro le procedure.

لا تنسخ كل شيء: الأسطر في الأعلى يكتبها Lazarus وحده عندما تضع القطع في الـ Form. أنت تكتب فقط الأسطر داخل الإجراءات.

不要全部照抄：上面那些行是你往 Form 里放组件时 Lazarus 自己写的。你只写过程里面的那几行。

interface

uses
  Classes, SysUtils, Forms, Controls, Graphics, Dialogs, StdCtrls;

  TForm1 = class(TForm)
    Button1: TButton;
    Button2: TButton;
    Label1: TLabel;
    procedure Button1Click(Sender: TObject);
    procedure Button2Click(Sender: TObject);
  private

  public

  end;

var
  Form1: TForm1;

implementation

{$R *.lfm}

{ TForm1 }

procedure TForm1.Button1Click(Sender: TObject);
begin
  Label1.Caption := 'APERTO';
  Label1.Font.Color := clGreen;
end;

procedure TForm1.Button2Click(Sender: TObject);
begin
  Label1.Caption := 'CHIUSO';
  Label1.Font.Color := clRed;
end;

end.

VARIABILE = una scatola con un nome dentro c'e' un valore
STRING  = testo, sempre tra apici:   'Ciao'   '5'
INTEGER = numero intero, senza apici:  5   12   -3
'5' + '3' = '53'  (attacca)      5 + 3 = 8  (somma)
Edit1.Text e Label1.Caption sono STRING
StrToInt: da String a Integer    '7' -> 7
IntToStr: da Integer a String     7 -> '7'
