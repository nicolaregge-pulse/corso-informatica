Che cosa fai in quest'ora

In questa ora costruisci la prima parte del Mastermind: il computer pensa un codice segreto di 4 cifre (da 1 a 6) con Random; tu provi, e un Memo ricorda tutti i tentativi. Dopo 10 minuti il computer ti mostra già il suo codice segreto.

এই ঘণ্টায় তুমি ধাপে ধাপে একটা খেলা/প্রোগ্রাম বানাবে। প্রতিটি ধাপ শেষে «Ho fatto!» চাপো।

Percorso facilitato: 3 passi

Per chi oggi fa fatica: fai solo questi 3 passi. Va bene così: è un programma vero.

যার আজ কঠিন লাগছে: শুধু এই ৩টা ধাপ করো। এটাও আসল প্রোগ্রাম।

4Dove tiene il segreto il programma

Premi F12: vedi il codice. Cerca la parola private. Sotto, scrivi le due righe. Sono due variabili (scatole che ricordano): una è un testo, l'altra un numero.

F12 চাপো। private শব্দটা খোঁজো। তার নিচে দুটো লাইন লেখো: একটা লেখা (String), একটা সংখ্যা (Integer)।

  private
    Segreto: String;      // il codice segreto, per esempio '3142'
    Tentativi: Integer;   // quanti tentativi hai fatto
da fare

5Il computer sceglie il codice (Random)

Torna alla Form1 (F12). Doppio clic su un punto vuoto della Form1 (non sulle scritte): si apre procedure TForm1.FormCreate. Riscrivila così. Randomize mescola i numeri; Random(6) dà un numero da 0 a 5, il + 1 lo porta da 1 a 6; il ciclo for lo fa 4 volte e il + attacca le cifre, come '5' + '3' = 53.

ফর্মের খালি জায়গায় ডাবল ক্লিক করো, FormCreate খুলবে। নিচের কোড লেখো। Random(6) 0 থেকে 5 দেয়, +1 করলে 1 থেকে 6।

procedure TForm1.FormCreate(Sender: TObject);
var
  i: Integer;
begin
  Randomize;
  Segreto := '';
  for i := 1 to 4 do
    Segreto := Segreto + IntToStr(Random(6) + 1);
  Tentativi := 0;
  Label2.Caption := 'Codice segreto: ' + Segreto;
end;

7La casella, il bottone e il Memo

Nella palette Standard metti nella Form1: una casella di testo (TEdit, l'icona con le lettere ab) = Edit1; un bottone OK (TButton) = Button1 con Caption Prova; un TMemo grande = Memo1. In Edit1 cancella il testo (Text). Il Memo è il foglio dei tentativi: dentro cancella la riga (Lines).

Standard থেকে: Edit1 (লেখার ঘর), Button1 (Caption: Prova), Memo1 (বড় ঘর)। Edit1-এর Text মুছে দাও।

da fare

8Il bottone Prova

Doppio clic sul bottone Prova: si apre Button1Click. Riscrivila così. Il computer guarda le 4 cifre una per una e conta quelle giuste al posto giusto. tentativo[i] è la cifra numero i.

Prova বাটনে ডাবল ক্লিক করো। নিচের কোড লেখো। কম্পিউটার চারটা সংখ্যা একটা একটা করে মেলায়।

procedure TForm1.Button1Click(Sender: TObject);
var
  i, giuste: Integer;
  tentativo: String;
begin
  tentativo := Edit1.Text;
  if Length(tentativo) <> 4 then
  begin
    Label1.Caption := 'Scrivi 4 cifre!';
    Exit;
  end;
  Tentativi := Tentativi + 1;
  giuste := 0;
  for i := 1 to 4 do
    if tentativo[i] = Segreto[i] then
      giuste := giuste + 1;
  Memo1.Lines.Add(IntToStr(Tentativi) + ') ' + tentativo + ' -> giuste: ' + IntToStr(giuste));
  if giuste = 4 then
    Label1.Caption := 'BRAVO! Hai indovinato in ' + IntToStr(Tentativi) + ' tentativi'
  else
    Label1.Caption := 'Cifre al posto giusto: ' + IntToStr(giuste);
  Edit1.Clear;
end;

আটকে গেলে: তিনটি সাহায্য, একটা একটা করে।

Aiuto 1: un indizio

Il codice segreto è una String di 4 cifre. Si costruisce con un ciclo for e Segreto := Segreto + IntToStr(Random(6) + 1);. Le variabili Segreto e Tentativi vanno sotto private. In Button1Click ricorda var prima di begin.

Aiuto 2: il pezzo difficile

Il pezzo più difficile è il confronto: if tentativo[i] = Segreto[i] then giuste := giuste + 1; dentro il ciclo for i := 1 to 4 do.

Aiuto 3: il unit1.pas completo

Prima prova da solo con gli aiuti 1 e 2. Se copi, poi spiega a voce con parole tue che cosa fa ogni pezzo: è la prova che hai capito. Se il file non parte, controlla che i componenti della Form abbiano gli stessi nomi (Button1, Edit1, Label1, Memo1…).

unit Unit1;

{$mode objfpc}{$H+}

interface

uses
  Classes, SysUtils, Forms, Controls, Graphics, Dialogs, StdCtrls;

type
  TForm1 = class(TForm)
    Button1: TButton;      // Prova
    Edit1: TEdit;          // dove scrivi il tuo tentativo (4 cifre)
    Label1: TLabel;        // il risultato del tentativo
    Label2: TLabel;        // il codice segreto (per ora lo vediamo, poi lo nascondiamo)
    Memo1: TMemo;          // la lista dei tentativi
    procedure Button1Click(Sender: TObject);
    procedure FormCreate(Sender: TObject);
  private
    Segreto: String;       // il codice segreto, per esempio '3142'
    Tentativi: Integer;    // quanti tentativi hai fatto
  public
  end;

var
  Form1: TForm1;

implementation

{$R *.lfm}

procedure TForm1.FormCreate(Sender: TObject);
var
  i: Integer;
begin
  Randomize;                         // mescola i numeri a caso
  Segreto := '';
  for i := 1 to 4 do
    Segreto := Segreto + IntToStr(Random(6) + 1);   // una cifra da 1 a 6
  Tentativi := 0;
  Label2.Caption := 'Codice segreto: ' + Segreto;
end;

procedure TForm1.Button1Click(Sender: TObject);
var
  i, giuste: Integer;
  tentativo: String;
begin
  tentativo := Edit1.Text;
  if Length(tentativo) <> 4 then
  begin
    Label1.Caption := 'Scrivi 4 cifre!';
    Exit;
  end;
  Tentativi := Tentativi + 1;
  giuste := 0;
  for i := 1 to 4 do
    if tentativo[i] = Segreto[i] then
      giuste := giuste + 1;
  Memo1.Lines.Add(IntToStr(Tentativi) + ') ' + tentativo + ' -> giuste: ' + IntToStr(giuste));
  if giuste = 4 then
    Label1.Caption := 'BRAVO! Hai indovinato in ' + IntToStr(Tentativi) + ' tentativi'
  else
    Label1.Caption := 'Cifre al posto giusto: ' + IntToStr(giuste);
  Edit1.Clear;
end;

end.
