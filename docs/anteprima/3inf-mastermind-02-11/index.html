Facoltativo: metti il progetto nel tuo repository «lazarus» su GitHub
  1. Apri github.com e il tuo repository lazarus. Se non lo hai, chiedilo all'assistente qui sotto.
  2. Premi Add file (o «Aggiungi file») → Upload files (o «Carica file»).
  3. Apri Esplora file (Win + E), vai in Documenti e trascina nella pagina l'intera cartella mastermind, non i singoli file: una cartella per ogni progetto.
  4. In basso premi Commit changes (o «Salva modifiche»).

ঐচ্ছিক: GitHub-এ lazarus রিপজিটরিতে Add file → Upload files, পুরো mastermind ফোল্ডার টেনে আনো, তারপর Commit changes।
