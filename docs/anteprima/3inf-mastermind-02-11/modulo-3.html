2La diapositiva (TPanel)

Nella palette Standard clicca TPanel e trascina un rettangolo grande nella Form1: è Panel1. Nell'Ispettore oggetti: Caption = Ciao, sono io!, Font → Size = 36. Il pannello è la tua diapositiva.

Standard থেকে TPanel রাখো (বড়)। Caption = Ciao, sono io!, Font Size = 36।

da fare

3Due bottoni e il contatore

Metti sotto il pannello due bottoni TButton: Button1 con Caption Indietro e Button2 con Caption Avanti. In mezzo una TLabel (Label1) con Caption 1 / 4.

দুটো বাটন: Indietro (Button1), Avanti (Button2)। মাঝখানে Label1: 1 / 4।

da fare

4Il numero della diapositiva

Premi F12. Sotto private scrivi le due righe: N è il numero della diapositiva (0, 1, 2, 3); Mostra è una procedura nostra. Poi premi insieme Ctrl + Maiusc + C: Lazarus scrive da solo lo scheletro di Mostra più in basso.

private-এর নিচে N আর Mostra লেখো। Ctrl+Maiusc+C চাপো: Lazarus নিজেই কাঠামো বানাবে।

  private
    N: Integer;        // quale diapositiva stiamo guardando (0, 1, 2, 3)
    procedure Mostra;
da fare

5Le scritte e i colori

Sopra la riga var (quella con Form1: TForm1;) aggiungi la parte const con le 4 diapositive: le scritte e i colori. array[0..3] = una fila di 4 scatole numerate da 0 a 3. Cambia le scritte con parole tue quando vuoi.

var Form1-এর ওপরে const যোগ করো: চারটা লেখা আর চারটা রং।

const
  Scritte: array[0..3] of String = ('Ciao, sono io!', 'Il mio gioco', 'La mia squadra', 'Grazie!');
  Colori: array[0..3] of TColor = (clYellow, clAqua, clLime, clSilver);
da fare

6Mostra la diapositiva

Scrivi il corpo di Mostra (cambia scritta, colore e contatore) e fai partire la prima diapositiva da FormCreate (doppio clic su un punto vuoto della Form1).

Mostra-র ভেতরের কোড লেখো। FormCreate-এ N := 0; Mostra; লেখো।

procedure TForm1.Mostra;
begin
  Panel1.Caption := Scritte[N];
  Panel1.Color := Colori[N];
  Label1.Caption := IntToStr(N + 1) + ' / 4';
end;

procedure TForm1.FormCreate(Sender: TObject);
begin
  N := 0;
  Mostra;
end;
da fare

7Avanti e Indietro

Doppio clic su Avanti (Button2) e su Indietro (Button1) e scrivi le due procedure. Dopo l'ultima diapositiva si torna alla prima.

Avanti আর Indietro বাটনে ডাবল ক্লিক করে কোড লেখো।

procedure TForm1.Button2Click(Sender: TObject);   // Avanti
begin
  if N < 3 then N := N + 1 else N := 0;
  Mostra;
end;

procedure TForm1.Button1Click(Sender: TObject);   // Indietro
begin
  if N > 0 then N := N - 1 else N := 3;
  Mostra;
end;

9Il timer: va avanti da solo

Nella palette System clicca TTimer e clicca nella Form1 (appare un orologio, solo in progettazione): Timer1. Nell'Ispettore: Interval = 2000 (sono 2 secondi) e Enabled = False. Poi una TCheckBox (Standard) con Caption Automatico. Doppio clic sulla casella e doppio clic sul Timer, e scrivi le due procedure.

System ট্যাব থেকে TTimer রাখো: Interval = 2000, Enabled = False। একটা CheckBox: Automatico। কোড লেখো।

procedure TForm1.CheckBox1Change(Sender: TObject);
begin
  Timer1.Enabled := CheckBox1.Checked;
end;

procedure TForm1.Timer1Timer(Sender: TObject);
begin
  Button2Click(Sender);        // ogni 2 secondi fa come se premessi Avanti
end;

Manda al prof (ora 3)

Sei bloccato? Tre aiuti, uno alla volta

আটকে গেলে: তিনটি সাহায্য, একটা একটা করে।

Aiuto 1: un indizio

N è il numero della diapositiva. Scritte[N] e Colori[N] prendono il testo e il colore giusti. Avanti fa N + 1 (dopo la 3 torna a 0), Indietro fa N - 1. Il timer chiama Avanti da solo ogni 2 secondi.

Aiuto 2: il pezzo difficile

Se la procedura Mostra non viene creata: sotto private deve esserci procedure Mostra;, poi Ctrl + Maiusc + C. La riga uses deve contenere ExtCtrls (per TPanel e TTimer): Lazarus la aggiunge da solo quando metti i componenti.

Aiuto 3: il unit1.pas completo

Prima prova da solo con gli aiuti 1 e 2. Se copi, poi spiega a voce con parole tue che cosa fa ogni pezzo: è la prova che hai capito. Se il file non parte, controlla che i componenti della Form abbiano gli stessi nomi (Button1, Edit1, Label1, Memo1…).

unit Unit1;

{$mode objfpc}{$H+}

interface

uses
  Classes, SysUtils, Forms, Controls, Graphics, Dialogs, StdCtrls, ExtCtrls;

type
  TForm1 = class(TForm)
    Panel1: TPanel;        // la "diapositiva": cambia scritta e colore
    Label1: TLabel;        // per esempio "2 / 4"
    Button1: TButton;      // Indietro
    Button2: TButton;      // Avanti
    CheckBox1: TCheckBox;  // Automatico
    Timer1: TTimer;        // Interval = 2000 (2 secondi), Enabled = False
    procedure Button1Click(Sender: TObject);
    procedure Button2Click(Sender: TObject);
    procedure CheckBox1Change(Sender: TObject);
    procedure FormCreate(Sender: TObject);
    procedure Timer1Timer(Sender: TObject);
  private
    N: Integer;            // quale diapositiva stiamo guardando (0, 1, 2, 3)
    procedure Mostra;
  public
  end;

const
  Scritte: array[0..3] of String = ('Ciao, sono io!', 'Il mio gioco', 'La mia squadra', 'Grazie!');
  Colori: array[0..3] of TColor = (clYellow, clAqua, clLime, clSilver);

var
  Form1: TForm1;

implementation

{$R *.lfm}

procedure TForm1.Mostra;
begin
  Panel1.Caption := Scritte[N];
  Panel1.Color := Colori[N];
  Label1.Caption := IntToStr(N + 1) + ' / 4';
end;

procedure TForm1.FormCreate(Sender: TObject);
begin
  N := 0;
  Timer1.Enabled := False;
  Mostra;
end;

procedure TForm1.Button2Click(Sender: TObject);   // Avanti
begin
  if N < 3 then N := N + 1 else N := 0;
  Mostra;
end;

procedure TForm1.Button1Click(Sender: TObject);   // Indietro
begin
  if N > 0 then N := N - 1 else N := 3;
  Mostra;
end;

procedure TForm1.CheckBox1Change(Sender: TObject);
begin
  Timer1.Enabled := CheckBox1.Checked;
end;

procedure TForm1.Timer1Timer(Sender: TObject);
begin
  Button2Click(Sender);        // ogni 2 secondi fa come se premessi Avanti
end;

end.
