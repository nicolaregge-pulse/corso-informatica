2Le cifre esatte e le cifre spostate

Il vero Mastermind dice due cose: quante cifre sono esatte (giuste, al posto giusto) e quante spostate (giuste, ma al posto sbagliato). Esempio: codice 1234, tu provi 1243: esatte 2 (l'1 e il 2), spostate 2 (il 4 e il 3). Per non contare due volte la stessa cifra, usiamo due liste di vero/falso: una per il codice e una per il tentativo. In Button1Click cambia le righe var così:

আসল Mastermind দুটো বলে: esatte (ঠিক জায়গায় ঠিক সংখ্যা) আর spostate (ঠিক সংখ্যা, ভুল জায়গায়)। var অংশ বদলাও।

var
  i, j, esatte, spostate: Integer;
  tentativo: String;
  usataS, usataT: array[1..4] of Boolean;
da fare

3Conta le esatte

In Button1Click cancella il vecchio giuste e il suo ciclo. Dopo Tentativi := Tentativi + 1; scrivi: prima si azzerano le liste, poi si contano le esatte.

giuste-এর পুরনো অংশ মুছে নিচের কোড লেখো: আগে তালিকা খালি, তারপর esatte গোনো।

  for i := 1 to 4 do
  begin
    usataS[i] := False;
    usataT[i] := False;
  end;
  esatte := 0;
  for i := 1 to 4 do
    if tentativo[i] = Segreto[i] then
    begin
      esatte := esatte + 1;
      usataS[i] := True;
      usataT[i] := True;
    end;
da fare

4Conta le spostate

Subito sotto scrivi il secondo pezzo. Per ogni cifra del tentativo non ancora usata, la cerca nel codice tra le cifre non ancora usate. Break = esci dal ciclo appena la trovi.

এর নিচে spostate গোনার কোড লেখো। Break = পেলেই ঘুরানো থামাও।

  spostate := 0;
  for i := 1 to 4 do
    if not usataT[i] then
      for j := 1 to 4 do
        if (not usataS[j]) and (tentativo[i] = Segreto[j]) then
        begin
          spostate := spostate + 1;
          usataS[j] := True;
          Break;
        end;
da fare

Memo আর Label1-এর লাইন বদলাও। F9 চাপো, Label2-এর কোড দেখে পরীক্ষা করো।

  Memo1.Lines.Add(IntToStr(Tentativi) + ') ' + tentativo + ' -> esatte: ' +

6Il bottone Nuova partita

Nella palette Standard metti un secondo bottone TButton con Caption Nuova partita (è Button2). Doppio clic su di lui. Scrivi la procedura: sceglie un codice nuovo e pulisce tutto. Poi in FormCreate cancella le righe del codice e scrivi solo Randomize; e Button2Click(Sender);: all'avvio il programma fa come se premessi Nuova partita.

দ্বিতীয় বাটন: Caption = Nuova partita (Button2)। ডাবল ক্লিক করে কোড লেখো। FormCreate-এ শুধু Randomize; আর Button2Click(Sender); রাখো।

procedure TForm1.Button2Click(Sender: TObject);
var
  i: Integer;
begin
  Segreto := '';
  for i := 1 to 4 do
    Segreto := Segreto + IntToStr(Random(6) + 1);
  Tentativi := 0;
  Memo1.Clear;
  Edit1.Clear;
  Label2.Caption := 'Codice segreto: ' + Segreto;
  Label1.Caption := 'Partita nuova: indovina le 4 cifre (da 1 a 6)';
end;

procedure TForm1.FormCreate(Sender: TObject);
begin
  Randomize;
  Button2Click(Sender);
end;

9Le regole e il record

Clicca la scheda Regole e metti una Label: sarà Label3. Clicca la scheda Record e mettine un'altra: Label4. Poi nella parte private aggiungi una variabile, e in FormCreate scrivi i due testi (sono le righe da aggiungere, prima di Button2Click(Sender);).

Regole ট্যাবে Label3, Record ট্যাবে Label4 রাখো। private-এ Record_ যোগ করো। FormCreate-এ দুটো লেখা লেখো।

    Record_: Integer;     // il minor numero di tentativi (0 = nessun record)

  Record_ := 0;

  if esatte = 4 then

Manda al prof (ora 2)

Sei bloccato? Tre aiuti, uno alla volta

আটকে গেলে: তিনটি সাহায্য, একটা একটা করে।

Aiuto 1: un indizio

Esatte: confronti tentativo[i] con Segreto[i] stessa posizione. Spostate: per le cifre del tentativo non esatte, cerchi nel codice una cifra uguale non ancora usata (usataS). Il tasto Nuova partita ricomincia: svuota il Memo e sceglie un codice nuovo.

Aiuto 2: il pezzo difficile

Se le schede non funzionano: i componenti devono stare DENTRO la scheda Gioco (Ctrl + X, clic sulla scheda, Ctrl + V). Il record sta in una variabile Record_ sotto private.

Aiuto 3: il unit1.pas completo

Prima prova da solo con gli aiuti 1 e 2. Se copi, poi spiega a voce con parole tue che cosa fa ogni pezzo: è la prova che hai capito. Se il file non parte, controlla che i componenti della Form abbiano gli stessi nomi (Button1, Edit1, Label1, Memo1…).

unit Unit1;

{$mode objfpc}{$H+}

interface

uses
  Classes, SysUtils, Forms, Controls, Graphics, Dialogs, StdCtrls, ComCtrls;

type
  TForm1 = class(TForm)
    PageControl1: TPageControl;   // le schede
    TabSheet1: TTabSheet;         // scheda Gioco
    TabSheet2: TTabSheet;         // scheda Regole
    TabSheet3: TTabSheet;         // scheda Record
    Button1: TButton;             // Prova
    Button2: TButton;             // Nuova partita
    Edit1: TEdit;                 // il tuo tentativo
    Label1: TLabel;               // risultato del tentativo
    Label2: TLabel;               // il codice segreto (per provare)
    Label3: TLabel;               // le regole (scheda Regole)
    Label4: TLabel;               // il record (scheda Record)
    Memo1: TMemo;                 // i tentativi
    procedure Button1Click(Sender: TObject);
    procedure Button2Click(Sender: TObject);
    procedure FormCreate(Sender: TObject);
  private
    Segreto: String;
    Tentativi: Integer;
    Record_: Integer;             // il minor numero di tentativi (0 = nessun record)
  public
  end;

var
  Form1: TForm1;

implementation

{$R *.lfm}

procedure TForm1.FormCreate(Sender: TObject);
begin
  Randomize;
  Record_ := 0;
  Label3.Caption := 'Il computer pensa 4 cifre da 1 a 6. ' +
    'Tu provi. "Esatte" = cifra giusta al posto giusto. ' +
    '"Spostate" = cifra giusta ma al posto sbagliato.';
  Label4.Caption := 'Record: nessuno (gioca una partita!)';
  Button2Click(Sender);              // comincia una partita nuova
end;

procedure TForm1.Button2Click(Sender: TObject);   // Nuova partita
var
  i: Integer;
begin
  Segreto := '';
  for i := 1 to 4 do
    Segreto := Segreto + IntToStr(Random(6) + 1);
  Tentativi := 0;
  Memo1.Clear;
  Edit1.Clear;
  Label2.Caption := 'Codice segreto: ' + Segreto;
  Label1.Caption := 'Partita nuova: indovina le 4 cifre (da 1 a 6)';
end;

procedure TForm1.Button1Click(Sender: TObject);   // Prova
var
  i, j, esatte, spostate: Integer;
  tentativo: String;
  usataS, usataT: array[1..4] of Boolean;
begin
  tentativo := Edit1.Text;
  if Length(tentativo) <> 4 then
  begin
    Label1.Caption := 'Scrivi 4 cifre!';
    Exit;
  end;
  Tentativi := Tentativi + 1;
  for i := 1 to 4 do
  begin
    usataS[i] := False;
    usataT[i] := False;
  end;
  esatte := 0;
  for i := 1 to 4 do                      // prima le esatte
    if tentativo[i] = Segreto[i] then
    begin
      esatte := esatte + 1;
      usataS[i] := True;
      usataT[i] := True;
    end;
  spostate := 0;
  for i := 1 to 4 do                      // poi le spostate
    if not usataT[i] then
      for j := 1 to 4 do
        if (not usataS[j]) and (tentativo[i] = Segreto[j]) then
        begin
          spostate := spostate + 1;
          usataS[j] := True;
          Break;
        end;
  Memo1.Lines.Add(IntToStr(Tentativi) + ') ' + tentativo + ' -> esatte: ' +
    IntToStr(esatte) + '  spostate: ' + IntToStr(spostate));
  if esatte = 4 then
  begin
    Label1.Caption := 'BRAVO! Indovinato in ' + IntToStr(Tentativi) + ' tentativi';
    if (Record_ = 0) or (Tentativi < Record_) then
    begin
      Record_ := Tentativi;
      Label4.Caption := 'Record: ' + IntToStr(Record_) + ' tentativi';
    end;
  end
  else
    Label1.Caption := 'Esatte: ' + IntToStr(esatte) + '  Spostate: ' + IntToStr(spostate);
  Edit1.Clear;
end;

end.
