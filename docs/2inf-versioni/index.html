Come si legge
  1. Ver1 ✔ = su GitHub c'è una prima versione di oggi della calcolatrice (un commit di oggi con .lpi .pas .lfm).
  2. Codice V1 ✔ = in quella prima versione il codice ha il + e il x.
  3. Ver2 ✔ = su GitHub c'è una seconda versione di oggi (un commit successivo di oggi con il progetto cambiato).
  4. Codice V2 ✔ = nella seconda versione il codice ha anche il − e il DIV.
  5. Voto proposto = 40 +20 (Ver1 con Codice V1) +15 (Ver2 con Codice V2) +5 (almeno una release di oggi), massimo 80; eccezioni decise dal prof.
Un ✔ si clicca e apre il commit su GitHub, per vedere il codice. Un ✘ si tocca e dice che cosa manca. Le release sono scritte piccole sotto il nome.
