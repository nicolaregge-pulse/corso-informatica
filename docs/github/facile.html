Procedura facilitata: 4 cartelle in 10 minuti

Tutto su github.com, con il mouse. Niente editor, niente Esplora file. Ogni cartella si crea scrivendo il suo nome con una barra / davanti a README.md: la barra crea la cartella.

1. Apri il tuo repository «lazarus»

  1. Vai su github.com.
  2. In alto a destra clicca la tua foto, poi Your repositories (i tuoi repository).
  3. Clicca lazarus.
FATTO! Vedi la pagina del tuo repository lazarus.

2. Crea la cartella «primo-programma»

  1. Clicca il bottone Add file (a sinistra del bottone verde «Code»), poi Create new file (crea un file nuovo).
  2. In alto, nella casella del nome, incolla questo (bottone Copia, poi clic nella casella e Ctrl+V):
primo-programma/README.md
  1. Nel riquadro grande sotto incolla:
Il mio primo programma Lazarus
  1. Clicca il bottone verde Commit changes… in alto a destra, poi di nuovo Commit changes nella finestrella.
FATTO! Nel repository c'è la cartella primo-programma.

3. Crea la cartella «esercizio-3»

  1. Torna al repository: in alto clicca la scritta lazarus.
  2. Add file → Create new file. Nome:
esercizio-3/README.md
  1. Testo:
Qui andrà l'esercizio 3
  1. Commit changes… → Commit changes.
FATTO! C'è la cartella esercizio-3.

4. Crea la cartella «esercizio-4»

  1. Torna al repository (scritta lazarus in alto). Add file → Create new file. Nome:
esercizio-4/README.md
  1. Testo:
Qui andrà l'esercizio 4
  1. Commit changes… → Commit changes.
FATTO! C'è la cartella esercizio-4.

5. La cartella «salvadanaio» (se non c'è ancora)

  1. Torna al repository. Add file → Upload files (carica file).
  2. Apri Esplora file, trova la cartella del tuo salvadanaio e trascinala dentro la pagina (tieni premuto, passa sull'icona di Chrome in basso, lascia al centro della pagina).
  3. Aspetta la barra verde piena e clicca Commit changes.

La cartella si deve chiamare salvadanaio. Se si chiama in un altro modo, va bene lo stesso per oggi: la sistemiamo insieme la prossima volta.

FATTO! Il tuo repository ha 4 cartelle: primo-programma, salvadanaio, esercizio-3, esercizio-4.

6. Il tuo README (Fallo tuo)

  1. Nel repository clicca il file README.md (quello fuori dalle cartelle), poi la matita in alto a destra.
  2. Cancella tutto (Ctrl+A, Canc) e incolla, poi cambia il nome con il tuo:
# I miei progetti Lazarus — Sono (il tuo nome), 2INF. 1. primo-programma 2. salvadanaio 3. esercizio-3 4. esercizio-4
  1. Commit changes… → Commit changes.
FATTO! Il tuo repository si presenta da solo.

7. Togliere il file .exe (trucco veloce)

  1. Nel repository apri la cartella e clicca il file che finisce con .exe.
  2. Clicca la matita (a destra, sopra il riquadro grigio): si apre una pagina con «edit» nell'indirizzo.
  3. Nella barra degli indirizzi fai doppio clic sulla parola edit e scrivi al suo posto delete, poi premi Invio.
  4. Clicca il bottone verde Commit changes…, poi Commit changes.
FATTO! Il file .exe non c'è più.

I file sparsi del progetto vecchio li mettiamo a posto tutti insieme la prossima lezione. Bloccato? Scrivi all'assistente in fondo alla pagina della lezione.
