Come si crea un progetto nuovo in Lazarus

كيف أنشئ مشروعًا جديدًا في Lazarus

怎么在 Lazarus 里新建一个项目

Vale per ogni progetto dell'anno. Tutti i tuoi progetti stanno nella cartella Documenti → Lazarus. Ogni progetto ha la sua cartella: un progetto = una cartella.

هذه الخطوات لكل مشروع. كل مشاريعك في المجلد Documenti ← Lazarus. لكل مشروع مجلده: مشروع واحد = مجلد واحد.

每个项目都这样做。你所有的项目都在文件夹 Documenti → Lazarus 里。每个项目有自己的文件夹：一个项目 = 一个文件夹。

Documenti\
  Lazarus\          <- TUTTI i miei progetti
    Ciao\           <- UN progetto = UNA cartella
    Calcolatrice\
    (prossimo)\

Fai un passo alla volta. Quando hai finito un passo, clicca Fatto.

نفّذ خطوة واحدة في كل مرة. عندما تنتهي اضغط «Fatto» (تمّ).

一次只做一步。做完一步，点「Fatto」（完成）。

0 passi fatti

Per riaprire un progetto

Menu Progetto → Apri progetto… → a sinistra Documenti → doppio clic su Lazarus → doppio clic sulla cartella del progetto → clic sul file che finisce con .lpi → Apri.

لفتح مشروع من جديد: قائمة «Progetto» ← «Apri progetto» ← Documenti ← Lazarus ← مجلد المشروع ← الملف الذي ينتهي بـ ‎.lpi‎ ← «Apri» (فتح).

重新打开项目：菜单 Progetto →「Apri progetto」→ Documenti → Lazarus → 项目文件夹 → 以 .lpi 结尾的文件 →「Apri」（打开）。
