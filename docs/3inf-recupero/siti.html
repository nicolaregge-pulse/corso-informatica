Legenda: che cosa vuol dire ogni cerchio rosso e gli errori più comuni
Cerchio rossoChe cosa mancaCome si sistema
○ indexnella cartella principale non c'è index.html (la Home)file pronti → index.html; se i file sono in una sottocartella (es. Mio-sito/) vanno spostati nella principale
○ stylenon c'è style.css con quel nome esattofile pronti → style.css (non Style.css, stile.css)
○ competenzenon c'è competenze.htmlfile pronti → competenze.html; se c'è comp.html o un altro nome, creare quella giusta
○ passionenon c'è passione.htmlfile pronti → passione.html (non passioni.html)
○ sfondonel CSS manca background-image oppure nel repository non c'è nessuna immagine (.jpg/.png)foto come img/sfondo.jpg e la riga background-image nel CSS; attenzione ai .jfif e ai nomi lunghissimi
○ animazionenel CSS manca @keyframes (o transition)prendere lo style.css dei file pronti, che ha l'animazione «entra»
○ versionenella Home non c'è scritto Versione seguita da un numeroriga <footer>Versione 1.0</footer> in fondo a index.html; si alza a ogni merge

Altri errori visti in classe: sito dentro una sottocartella (Mio-sito/, sito_official/); nomi diversi da quelli richiesti (comp.html, contacts.html); immagine con estensione .jfif o nome di 90 caratteri; Pull Request fatta a se stesso invece che al compagno; copia doppia del sito in un'altra cartella.

Una scheda per allievo, dal sito più completo al meno. Le 7 cose: ✔ fatta, ○ manca. Voto sito = 40 + 40 × cose/7; voto di oggi = media con il quiz (il quiz non fatto conta dalle 12:50) − 3 per fuori lezione. Si aggiorna da sola ogni minuto (dati ogni 5).
