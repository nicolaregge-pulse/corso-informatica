I file pronti del tuo sito

Ogni file ha due bottoni Copia: uno per il nome e uno per il testo. Su GitHub: Add file → Create new file, incolla il nome, incolla il testo, Commit changes… → Commit changes. Se il file c'è già: aprilo, matita, Ctrl+A, incolla, Commit changes.

Metti solo i file che la tabella della lezione dice che ti mancano. Poi cambia le parole in MAIUSCOLO con le tue: è il tuo sito.

index.html

La Home. Cambia IL TUO NOME e le frasi in maiuscolo.

Nome del file (si copia anche questo):

index.html

Testo del file:

<!DOCTYPE html>
<html lang="it">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Il sito di IL TUO NOME</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <nav>
    <a href="index.html">Home</a>
    <a href="competenze.html">Competenze</a>
    <a href="passione.html">Passione</a>
  </nav>
  <main>
    <h1>Ciao, sono IL TUO NOME</h1>
    <p>Frequento la 3INF all'Istituto Piamarta. Questo è il mio sito personale.</p>
    <p>Di me ti dico che: SCRIVI QUI UNA FRASE SU DI TE.</p>
    <p>Da grande vorrei: SCRIVI QUI IL TUO SOGNO.</p>
  </main>
  <footer>Versione 1.0</footer>
</body>
</html>

style.css

Lo stile: menu, sfondo (img/sfondo.jpg) e animazione. Puoi cambiare il colore #1f6feb del menu.

Nome del file (si copia anche questo):

style.css

Testo del file:

body {
  margin: 0;
  font-family: Arial, sans-serif;
  color: #222;
  background-image: url("img/sfondo.jpg");
  background-size: cover;
  background-attachment: fixed;
}
nav {
  background: #1f6feb;
  padding: 14px;
  text-align: center;
}
nav a {
  color: white;
  margin: 0 14px;
  font-weight: bold;
  text-decoration: none;
}
nav a:hover {
  text-decoration: underline;
}
main {
  background: rgba(255, 255, 255, 0.9);
  max-width: 700px;
  margin: 30px auto;
  padding: 20px 26px;
  border-radius: 14px;
  animation: entra 1s ease;
}
footer {
  text-align: center;
  color: white;
  font-weight: bold;
  padding: 10px;
  text-shadow: 0 0 4px black;
}
@keyframes entra {
  from { opacity: 0; transform: translateY(30px); }
  to   { opacity: 1; transform: translateY(0); }
}
