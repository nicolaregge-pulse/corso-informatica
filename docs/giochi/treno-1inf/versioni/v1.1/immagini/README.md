# Le immagini della 1INF nel Treno blindato

Ogni immagine arriva da una consegna su Classroom (allegato al compito) e viene messa qui in automatico, con il nome di chi l'ha fatta.

1. `cattivi/` — PR-1, il disegno del mio cattivo. Entra anche nel gioco come faccia dei cattivi (cartella `../facce/`).
2. `paesaggi/` — PR-2, il disegno del paesaggio vicino ai binari.
3. `difetti/` — PR-3, la foto o lo screenshot del difetto.
4. `revisioni/` — PR-4, immagini della revisione.
5. `immagini.json` — l'elenco di tutte le immagini con l'autore: lo legge la galleria (`index.html`).

Lo script che le importa è `strumenti/importa_immagini_treno1inf.py` (dalla cartella delle consegne del repository riservato).
