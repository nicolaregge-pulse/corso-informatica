# Fonti registro — argomenti svolti 2025/26

File Excel esportati dal registro (argomenti svolti l'anno scorso), usati per
generare `ARGOMENTI-SVOLTI.md` e, in futuro, i programmi svolti per la Regione.

I nomi dei file usano la nomenclatura NUOVA 2026/27 (la classe che quella coorte
e diventata quest'anno):
1. `argomenti_2025-26_classe-2.xlsx` — coorte che nel 2026/27 e la Classe 2 (l'anno scorso era 1INFspe).
2. `argomenti_2025-26_classe-3.xlsx` — coorte che nel 2026/27 e la Classe 3 (l'anno scorso 2INFspe).
3. `argomenti_2025-26_classe-4.xlsx` — coorte che nel 2026/27 e la Classe 4 (l'anno scorso 3INF).

Contengono SOLO argomenti (Data, Ora, Disciplina, Argomento) e riepiloghi: nessun
nome di allievo. I dati personali del docente (cedolino, lettera d'incarico) NON
sono nel repository.
