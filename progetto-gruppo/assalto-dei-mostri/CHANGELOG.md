# Storia delle versioni

## v1.0 — 08/10/2026 — Il motore

1. Mostri che sbucano dai quattro lati, si toccano per colpirli.
2. Il vetro si crepa a ogni colpo dei mostri e si rompe dopo 3-5 colpi, con l'audio.
3. Livelli sempre più veloci, combo, coriandoli e record.
4. Il gioco legge i pezzi della classe da file separati (mostri, regole, grafica, testi, suoni) e segnala i file con un errore senza bloccarsi.
