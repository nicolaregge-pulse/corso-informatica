# Immagini del manuale

dall'eserciziario.

## Come aggiungere un'immagine (per Nicola)
1. Fai lo screenshot (in Windows: `Win + Shift + S`).
2. Salvalo in **questa cartella** con il nome atteso dal manuale.
3. Nel `manuale.md` il riferimento è già pronto, es.:
   `![descrizione](immagini/godot-avvio.png)`
