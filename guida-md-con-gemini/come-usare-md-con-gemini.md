# Come usare i file .md con Gemini — guida per l'allievo

**Versione 1.0 · vale per tutte le materie**

*Quando il prof ti dà una scheda in formato **.md** (Markdown), puoi darla a **Gemini**
(o a un'altra AI) per farti **spiegare** le parti difficili o **tradurre** nella tua
lingua. Ecco come, passo per passo.*

## 1. Cos'è un file .md e perché te lo diamo
1. Un file **.md** è **testo pulito** (si legge col Blocco note o su GitHub).
2. L'AI lo legge **molto bene**: niente immagini pesanti, solo il contenuto. Perfetto
   per farti spiegare o tradurre.

## 2. Apri Gemini
1. Nel browser vai su **gemini.google.com**.
2. Entra con il tuo **account della scuola**.

## 3. Dai il file all'AI
1. Apri il file **.md** (col Blocco note o su GitHub) e **seleziona tutto** il testo, poi **copialo**.
2. Torna su Gemini e **incolla** il testo nella casella del messaggio.
3. (In alternativa, se puoi, **carica** direttamente il file col pulsante di allegato.)

## 4. Cosa chiedere (esempi)
1. «Spiegami con parole semplici la parte che non capisco: [incolla la frase].»
2. «Traducimi questa scheda in [la tua lingua], mantenendo i termini tecnici.»
3. «Fammi **3 domande** per controllare se ho capito.»
4. «Dammi **un esempio in più**, diverso da quello della scheda.»
5. «Riassumimi in **5 punti** le cose importanti.»

## 5. Regola d'oro
1. L'AI serve per **capire meglio**, **non** per fare il compito al posto tuo.
2. Dopo che ti ha spiegato, **prova a rifarlo da solo** e a **spiegarlo a voce** a un
   compagno. Se lo sai spiegare, l'hai capito davvero.
