# Lazarus: gli schemi per la lavagna — 1INF — 28/10/2026 — Versione 1.0

## SCHEMA 1 — Da ricopiare sul quaderno

```
LAZARUS - IL MIO PRIMO PROGRAMMA
1. File > Chiudi tutto
2. Progetto > Nuovo progetto > Applicazione
3. Salva subito in una cartella nuova: ciao
4. TEdit = casella dove scrivo (Text)
5. TButton = bottone (Caption)
6. Doppio clic sul bottone = evento OnClick
7. ShowMessage('Ciao ' + Edit1.Text);
8. F9 = esegui
I 4 file importanti: .lpi .lpr .pas .lfm
```

## SCHEMA 2 — Le finestre di Lazarus

```
+--------------------------------------------------+
| MENU:  File  Progetto  Esegui ...                |
| PALETTE: [Standard]  [OK] [abc] [A] ...          |
+------------+-------------------------------------+
| ISPETTORE  |                                     |
| OGGETTI    |   FORM1  (la mia finestra)          |
|            |    +-----------------+              |
| Proprieta  |    | Edit1           |  <- TEdit    |
|  Caption   |    +-----------------+              |
|  Text      |       [ Saluta ]       <- TButton   |
| Eventi     |                                     |
|  OnClick   |   (F12 = vado al codice)            |
+------------+-------------------------------------+
| MESSAGGI: errori e avvisi                        |
+--------------------------------------------------+
```

## SCHEMA 3 — La cartella del progetto

```
ciao\                       <- UNA cartella = UN progetto
 |- ciao.lpi    progetto (+ opzioni)      TENERE
 |- ciao.lpr    programma principale      TENERE
 |- unit1.pas   il mio codice             TENERE
 |- unit1.lfm   com'e' fatta la finestra  TENERE
 |- ciao.lps    sessione (segnalibro)     si rifa'
 |- ciao.res    risorse (icona)           si rifa'
 |- ciao.ico    icona                     si rifa'
 |- ciao.exe    programma finito (F9)     si rifa'
 |- lib\        .o .ppu (compilatore)     si rifa'
 |- backup\     copie di sicurezza        si rifa'
```

## SCHEMA 4 — Dal clic al saluto

```
scrivo MARIO -> clic su [Saluta] -> OnClick -> Button1Click
   -> ShowMessage('Ciao ' + Edit1.Text) -> | Ciao MARIO  [OK] |
```
