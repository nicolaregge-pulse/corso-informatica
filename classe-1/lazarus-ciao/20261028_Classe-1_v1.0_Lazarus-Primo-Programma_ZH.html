01 Lazarus 是什么

Lazarus 是一个用来做其他程序的软件，可以做有窗口和按钮的程序，就像你每天用的那些程序一样。它像搭积木：拿一个现成的零件（一个按钮、一个输入框），放进窗口，然后写它要做什么。用的编程语言叫 Pascal。

今天我们做所有程序员都会做的第一个程序：「Ciao」（意大利语的「你好」）。在输入框里写你的名字，按一个按钮，程序就跟你打招呼：Ciao Ahmed。

打开 Lazarus：双击 Lazarus 的图标（老师会告诉你们它在哪里）。然后看第 02 章：在那里准备新项目和你的文件夹。

02 干净的开始：新项目和新文件夹

在往窗口里放零件之前，先准备好地方。一个项目 = 只有一个文件夹：你的程序的所有文件都放在一起，放在你的文件夹里。这样文件不会丢，也不会和别人的文件混在一起。

一次只做一步。每做完一步，看一看屏幕。

  1. 在 Lazarus 的左上角，点菜单 «File»（文件）。
  2. 在菜单里点 «Chiudi tutto»（全部关闭）。这样还开着的文件都会关掉。
  3. 如果 Lazarus 问你要不要保存一个旧项目，点 «No»（不）。
  4. 在上面点菜单 «Progetto»（项目）。
  5. 在菜单里点 «Chiudi progetto»（关闭项目）。如果这一项是灰色的，就点不了：没关系，直接做第 6 步。
  6. 现在做新项目。在上面点菜单 «Progetto»（项目）。
  7. 在菜单里点 «Nuovo progetto…»（新建项目）。会打开一个有列表的窗口。
  8. 在左边的列表里点 «Applicazione»（应用程序）。
  9. 在窗口下面点 «OK»（确定）。中间出现一个空的窗口 Form1。
  10. 马上保存。在上面点菜单 «Progetto»（项目）。
  11. 在菜单里点 «Salva progetto con nome…»（项目另存为）。会打开保存的窗口。
  12. 在窗口上面点按钮 «Nuova cartella»（新建文件夹）。（看不到？在窗口的空白地方点鼠标右键 → «Nuovo»（新建）→ «Cartella»（文件夹）。）
  13. 写文件夹的名字，然后按 Invio 键（回车键 Enter）：
    ciao
  14. 双击文件夹 ciao，进到里面。现在上面写着 ciao。
  15. 在下面的 «Nome file»（文件名）框里，写项目的名字：
    ciao.lpi
  16. 在右下角点 «Salva»（保存）。
  17. Lazarus 打开第二个窗口：问 unit（单元，就是代码文件）的名字。在 «Nome file»（文件名）框里保留或者写上：
    unit1.pas
  18. 在右下角点 «Salva»（保存）。
  19. 检查：看最上面 Lazarus 的标题栏，上面写着 ciao。完成：你的项目有了自己的文件夹！

03 Lazarus 的窗口

打开一个新项目时，你会看到好几个窗口。每个窗口都有自己的工作：

在哪里叫什么有什么用
在上面菜单和组件面板（palette）命令（«File» 文件、«Progetto» 项目、«Esegui» 运行……），下面是可以放进窗口的零件，分成几个标签页
在左边对象检查器（«Ispettore oggetti»）选中的零件的属性（文字、名字、颜色）和它的事件（点它的时候会发生什么）
在中间Form1，上面有很多小点你的程序的窗口：零件放在这里
在 Form 后面代码编辑器（unit1.pas）在这里写程序做什么
在下面消息（«Messaggi»）Lazarus 告诉你一切正常，或者错误在哪里

在 Form 和代码之间来回切换：按 F12 键。

抄到本子上

+--------------------------------------------------+
| MENU:  File  Progetto  Esegui ...                |
| PALETTE: [Standard]  [OK] [abc] [A] ...          |
+------------+-------------------------------------+
| ISPETTORE  |                                     |
| OGGETTI    |   FORM1  (la mia finestra)          |
|            |    +-----------------+              |
| Proprieta  |    | Edit1           |  <- TEdit    |
|  Caption   |    +-----------------+              |
|  Text      |       [ Saluta ]       <- TButton   |
| Eventi     |                                     |
|  OnClick   |   (F12 = vado al codice)            |
+------------+-------------------------------------+
| MESSAGGI: errori e avvisi                        |
+--------------------------------------------------+

图里的词（意大利语，和屏幕、黑板上一样）: MENU = 菜单；PALETTE = 组件面板；ISPETTORE OGGETTI = 对象检查器；Proprieta = 属性；Eventi = 事件；FORM1 (la mia finestra) = 我的窗口；F12 = vado al codice = 去看代码；MESSAGGI: errori e avvisi = 消息：错误和提醒。

04 组件面板：怎么选对零件

组件面板是上面菜单下面的一排图标。今天用的零件在 «Standard»（标准）标签里。选的时候问自己：用这个程序的人要做什么？

要……零件（组件）面板里的图标重要的属性
写东西TEdit（输入框）一个白色的框，写着「abc」或「ab|」Text = 框里写的内容
按一下，让事情发生TButton（按钮）一个写着「OK」的按钮Caption = 按钮上的字
读一段文字（只是看）TLabel（标签）一个「A」Caption = 看到的文字

放进窗口的方法：在面板里的图标上点一下，然后在 Form1 上你想放的地方点一下。Lazarus 会自己给它起名字：Edit1、Button1。名字（Name）就是你在代码里要用的。

05 练习：我的「Ciao」

一次一步。每做完一步看屏幕：应该和这里写的一模一样。

  1. 在面板的 «Standard» 标签里点 TEdit，再在 Form1 的左上方点一下。出现一个写着 Edit1 的输入框。
  2. 选中这个输入框，在对象检查器里找到属性 Text，删掉「Edit1」这几个字：输入框变成空的。
  3. 在面板里点 TButton，再在 Form1 里输入框的下面点一下。出现 Button1。
  4. 选中按钮，在对象检查器里把 Caption 改成 Saluta（意大利语「打招呼」）。完成：窗口准备好了！
  5. 双击按钮。代码打开了，光标在这里（// qui scrivi la tua riga 的意思是：在这里写你的那一行）：
    procedure TForm1.Button1Click(Sender: TObject);
begin
  // qui scrivi la tua riga
end;
  6. 在 begin 和 end; 中间写这一行：
    ShowMessage('Ciao ' + Edit1.Text);

一块一块地看是什么意思：

部分意思
ShowMessage( … )打开一个小窗口，里面有一条消息和 OK 按钮。括号里的就是消息
Edit1.Text输入框 Edit1 里写的文字（名字）
'Ciao '固定的文字，要放在两个单引号 ' 中间。Ciao 后面的空格是为了不变成「CiaoAhmed」
+把两段文字一个接一个连起来
;一条指令的结束（像句子末尾的句号）

合起来就是：「打开一个小窗口，写着 Ciao 和输入框里的名字」。就像黑板上画的：写 MARIO，按 Saluta，出现 Ciao MARIO 和 OK 按钮。这是回应按钮点击的函数：它叫 Button1Click。

抄到本子上

scrivo MARIO -> clic su [Saluta] -> OnClick -> Button1Click
   -> ShowMessage('Ciao ' + Edit1.Text) -> | Ciao MARIO  [OK] |

图里的词（意大利语，和屏幕、黑板上一样）: scrivo MARIO = 我写 MARIO；clic su [Saluta] = 点 Saluta 按钮；OnClick = 点击事件；Button1Click = 点击时运行的函数；最后出现小窗口 Ciao MARIO 和 OK。

06 保存并运行

文件夹 ciao 你在第 02 章已经做好了。现在只差一点点。

  1. 按 Ctrl + S：Lazarus 把所有东西保存到你的文件夹里。
  2. 按 F9（或者上面的绿色箭头 ▶）。Lazarus 准备好程序并运行它：打开的是你自己的窗口。
  3. 点输入框，写你的名字。
  4. 点 Saluta 按钮。打开一个小窗口，写着 Ciao 和你的名字。
  5. 点 OK。你成功了：你写出了你的第一个程序！
出错了？很正常，所有程序员都会遇到。 看下面的 «Messaggi»（消息）窗口：它会告诉你是哪一行。最常见的错误：少了 ;；把 := 写成了 =；少了一个单引号 '；这一行写在了 begin … end 的外面。

07 项目的文件，一个一个看

按了 F9 以后，用文件资源管理器（Esplora file）打开文件夹 ciao。Lazarus 做了很多文件。扩展名是文件名里点后面的字母：它说明这是什么类型的文件。看不到扩展名？在文件资源管理器的上面：«Visualizza»（查看）→ «Mostra»（显示）→ «Estensioni nomi file»（文件扩展名）。

第 1 组：项目

文件是什么里面有什么可以删除吗？
ciao.lpi项目信息（Lazarus Project Information）
像：项目卡片，上面有零件清单和组装说明		XML 格式的文字（尖括号 < 和 > 之间有标签的文字）：哪些文件属于这个项目，还有项目和编译器的选项，就是在菜单 «Progetto» → «Opzioni progetto…»（项目选项）里改的那些。双击这个文件就能重新打开项目不可以
ciao.lpr主程序（Lazarus PRogram）
像：比赛开始的哨声：让一切开始		几行 Pascal 代码，让一切开始运行并打开 Form1。不要动它不可以
ciao.lps会话（Lazarus Project Session）
像：书签：记住你停在哪里		编辑器里打开了哪些文件，标签页的顺序，光标在哪里。里面没有程序：删掉它，你的工作还全部都在可以：Lazarus 会再做一个
ciao.res资源（RESource）
像：书包，装着要放进 exe 的东西：图标和版本		程序的图标和版本，准备好放进 exe 里可以：Lazarus 会再做一个
ciao.ico图标（ICOn）
像：程序的头像		程序的小图，就是你在 Windows 任务栏上看到的那个可以：Lazarus 会再做一个

第 2 组：窗口和代码

文件是什么里面有什么可以删除吗？
unit1.lfm窗体 form（Lazarus ForM）
像：房间的平面图：家具放在哪里		窗口是什么样子：有哪些零件，在哪里，多大，Caption 和 Text不可以
unit1.pas单元 unit（一个 Pascal 代码文件）
像：菜谱：你自己写的步骤		你的代码：过程 Button1Click 和 Ciao 那一行。单元的扩展名也可以是 .pp不可以

第 3 组：做好的程序

文件是什么里面有什么可以删除吗？
ciao.exe可执行文件（EXEcutable），在项目文件夹里
像：烤好的蛋糕：没有菜谱也能吃		做好的程序，按 F9 做出来的。没有 Lazarus 也能打开可以：按 F9 再做一个

第 4 组：编译器的工作文件（编译器，意大利语 compilatore，是把 Pascal 变成电脑能运行的程序的软件）

文件是什么里面有什么可以删除吗？
lib\x86_64-win64\文件夹
像：厨房的桌子，在上面准备零件		做 exe 需要的中间零件（见下面几行）可以：Lazarus 会再做一个
.o目标文件（Object）
像：一样已经做熟的食材，只有一样		只有一个单元的机器码，比如 unit1.o可以
.ppuFree Pascal 编译好的单元（Pascal Precompiled Unit）
像：一个装好的零件，贴着标签说它会做什么		已经翻译好的单元的信息，比如 unit1.ppu可以
.compiled编译记录
像：小票：记得上一次是怎么做的		上一次项目是怎么编译的：这样 Lazarus 知道要不要全部重做可以
.or编译好的资源
像：已经合上的 .res 书包，准备装上去		准备好贴到 exe 上的 .res 文件可以
backup\备份文件夹
像：改作业之前先复印一份		保存一个原来就有的文件时，Lazarus 会把旧版本放在这里。项目文件的备份和原文件同名（unit1.pas、unit1.lfm、ciao.lpi……）；不属于项目的文件会多加一个 .bak（比如 prova.pas.bak）。第二次保存时这个文件夹才会出现可以

用 Lazarus 4 的普通设置，在 backup 文件夹外面找不到带 ~ 或 .bak 的备份。如果你看到了，说明有人改了备份的设置（菜单 «Strumenti»（工具）→ «Opzioni…»（选项），«Backup»（备份）页）。

要记住的规则：要保留的 4 个文件，也是要提交和放到 GitHub 上的，是 .lpi .lpr .pas .lfm。其他的 Lazarus 都会自己再做。

抄到本子上

ciao\                       <- UNA cartella = UN progetto
 |- ciao.lpi    progetto (+ opzioni)      TENERE
 |- ciao.lpr    programma principale      TENERE
 |- unit1.pas   il mio codice             TENERE
 |- unit1.lfm   com'e' fatta la finestra  TENERE
 |- ciao.lps    sessione                  si rifa'
 |- ciao.res    risorse (icona)           si rifa'
 |- ciao.ico    icona                     si rifa'
 |- ciao.exe    programma finito (F9)     si rifa'
 |- lib\x86_64-win64\
 |     .o .ppu .compiled .or (compilatore) si rifa'
 |- backup\     copie di sicurezza        si butta

图里的词（意大利语，和屏幕、黑板上一样）: UNA cartella = UN progetto = 一个文件夹 = 一个项目；TENERE = 保留；si rifa' = 会再做一个；si butta = 可以扔掉；progetto (+ opzioni) = 项目（和选项）；programma principale = 主程序；il mio codice = 我的代码；com'e' fatta la finestra = 窗口的样子；sessione = 会话；risorse (icona) = 资源（图标）；icona = 图标；programma finito = 做好的程序；compilatore = 编译器；copie di sicurezza = 备份。

08 做成你自己的

程序能运行了吗？现在把它变成你自己的。至少选一样：

  1. 用你的语言打招呼：把 'Ciao ' 换成 'Hello '、'مرحبا '、'你好 '、'Hola '……
  2. 窗口的标题：在 Form1 的空白地方点一下，在对象检查器里改 Caption（比如「Il saluto di Ahmed」，意思是「Ahmed 的问候」）。
  3. 颜色：还是在 Form1 上，属性 Color，从下拉列表里选一个颜色。
  4. 给做得快的同学：加一个 TLabel 和第二行 Label1.Caption := 'Ciao ' + Edit1.Text;：问候也会一直写在窗口里。

然后用 30 秒跟同学讲一讲：「我放了一个 TEdit 和一个 TButton；我点按钮的时候，函数 Button1Click 打开一个小窗口，写着 Ciao 和名字。」
