La mia scheda di presentazione (per GitHub)

Da scrivere in Google Documenti e consegnare su Classroom · Italiano • العربية • 中文 · Classe 1
Italiano.
Cosa devi fare (non serve l'account GitHub, lo creiamo insieme uno alla volta):
  1. Apri Google Documenti e crea un documento nuovo.
  2. Scrivi la tua presentazione (in italiano o nella tua lingua), con:
    1. il nome che vuoi mostrare;
    2. una cosa di te (da dove vieni, una passione);
    3. il tuo gioco / colore / cibo preferito;
    4. una cosa che vuoi imparare quest'anno.
  3. Se vuoi, aggiungi un'emoji o scrivi che foto ti piacerebbe mettere.
  4. Consegna il documento su Google Classroom.
Perché è importante: questo testo diventerà la tua prima pagina su GitHub — falla bella e tua! Quando tocca a te, la copi lì in un minuto.
Extra (facoltativo): scrivi con parole tue cos'è una "versione" e fai un esempio.
العربية.
ما المطلوب منك (لا حاجة إلى حساب GitHub، سننشئه معًا واحدًا تلو الآخر):
  1. افتح Google Documenti وأنشئ مستندًا جديدًا.
  2. اكتب تعريفًا بنفسك (بالإيطالية أو بلغتك)، يتضمّن:
    1. الاسم الذي تريد إظهاره؛
    2. شيئًا عنك (من أين أنت، شغفك)؛
    3. لعبتك / لونك / طعامك المفضّل؛
    4. شيئًا تريد أن تتعلّمه هذا العام.
  3. إن أردت، أضف إيموجي أو اكتب أيّ صورة تودّ وضعها.
  4. سلّم المستند على Google Classroom.
هذا النص سيصبح صفحتك الأولى على GitHub — اجعلها جميلة وخاصة بك. (اختياري: اكتب بكلماتك ما معنى «النسخة» مع مثال.)
中文（简体）。
你要做什么（不需要 GitHub 账号，我们会一个一个一起创建）：
  1. 打开 Google Documenti，新建一个文档。
  2. 写一段自我介绍（用意大利语或你的母语），包含：
    1. 你想展示的名字；
    2. 关于你的一件事（来自哪里、你的爱好）；
    3. 你最喜欢的游戏／颜色／食物；
    4. 今年你想学的一件事。
  3. 如果愿意，加一个表情符号，或写下你想放的照片。
  4. 把文档提交到 Google Classroom。
这段文字将成为你在 GitHub 上的第一个页面 —— 把它做得漂亮、有你自己的风格！（可选：用你自己的话写“版本”是什么，并举个例子。）
