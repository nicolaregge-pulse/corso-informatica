# Classe 1 — Corso di Informatica

Spazio del corso di **Informatica per la Classe 1** (istituto professionale).
È **separato** dal corso di Godot (che è per la seconda e la terza): qui si parte
dalle basi.

**Quattro moduli nell'anno:**
1. **Suite Google** — gli strumenti di tutti i giorni (Drive, Documenti, Fogli, Presentazioni, Gmail).
2. **Informatica di base** — hardware/software, file e cartelle, internet, sicurezza.
3. **Lazarus** — la prima programmazione: bottoni, caselle di testo, la calcolatrice.
4. **Assemblaggio PC** — le mani sull'hardware: montare un computer e farlo partire.

## File in questa cartella

- **`programma.md`** — la mappa dell'anno: cosa facciamo, in che ordine e perché.
  È il punto di partenza; da qui nasceranno, un modulo alla volta, il libro di
  testo e l'eserciziario.

## Come crescerà

Come per il corso di Godot, i contenuti veri andranno in un **libro di testo**
(`manuale.md`) e in un **eserciziario** (`eserciziario.md`) a **4 livelli di
aiuto**, versionati e resi in PDF. Si procede a **piccoli passi**, sempre con il
motore *Vinci subito · Fallo tuo · Mostralo*.
