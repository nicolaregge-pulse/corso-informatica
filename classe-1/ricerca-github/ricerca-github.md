# Ricerca — Cos'è GitHub e cos'è un repository

**Versione 1.0** — 18/09/2026
*Consegna per gli allievi: piccola ricerca per capire cos'è GitHub e cos'è un
repository, guardando il sito e cercando in rete; si scrive in Google Documenti e
si consegna su Classroom. Attività di avvicinamento PRIMA di creare gli account.
Testo per gli allievi: disponibile nelle 3 lingue (file monolingui
`ricerca-github-IT/AR/ZH-v1.0.pdf`, generati dagli HTML per i font cinese/arabo).
Questo `.md` è la fonte (italiano). Indirizzi marcati "scrivilo così"; bottoni per
posizione/colore.*

---

## 1. Cosa devi fare
1. Piccola ricerca: capire cos'è GitHub (il sito dove i programmatori salvano e
   condividono i loro progetti) e cos'è un repository. Guardare il sito, cercare
   in rete, scrivere le risposte in un documento e consegnare su Classroom. Si
   può scrivere prima nella propria lingua e poi tradurre in italiano.

## 2. Passi
1. **A. Apri il compito in Classroom.** Browser → barra in alto → `classroom.google.com` → Invio → account scuola → riquadro del corso → "Lavori del corso" → compito "Ricerca: cos'è GitHub".
2. **B. Crea il documento.** A destra "Il tuo lavoro" → "+ Aggiungi o crea" → "Documenti Google" → titolo "Cos'è GitHub".
3. **C. Fai la ricerca.** Nuova scheda → `github.com` (guarda il sito). Altra scheda → `google.com` → cerca "cosa è GitHub" (anche nella propria lingua) → leggi 1-2 risposte.
4. **D. Scrivi 4 risposte:** (1) cos'è GitHub; (2) cos'è un repository (una "cartella-progetto" con i file e la loro storia); (3) una cosa vista su github.com; (4) "Fallo tuo": un progetto/gioco su GitHub che piace. Se scritto nella propria lingua: `translate.google.com` → tua lingua a sinistra, Italiano a destra → copia e incolla.
5. **E. Consegna.** Il documento si salva da solo → torna al compito → bottone blu "Consegna" → conferma.

## 3. Quaderno e prova del nove
1. Prima di scrivere al computer: schema a mano sul quaderno con le risposte.
2. Prova del nove: raccontare a voce a un compagno, con parole proprie, cos'è GitHub.

## 4. Nota per il docente
1. Creare il compito in Classroom (Lavori del corso → Crea → Compito, titolo "Ricerca: cos'è GitHub").
2. Non serve l'account GitHub: le pagine pubbliche si vedono senza login.
3. Va fatta PRIMA della lezione di creazione degli account: così arrivano al "crea account" sapendo già dove sono.
