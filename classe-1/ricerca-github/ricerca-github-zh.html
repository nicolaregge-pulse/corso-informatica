研究 — 什么是 GitHub，什么是仓库（repository）

一年级 · Google Documenti + Classroom · 版本 1.0 · 中文（简体）
用拉丁字母写的词（如 github.com）是网址：请照原样输入。按钮按位置和颜色去找；意大利文词只是提示。
你要做什么。 做一个小研究，弄清楚什么是 GitHub（程序员保存和分享自己项目的网站）以及什么是仓库（repository）。看看网站，在网上搜索，把答案写进一个文档。然后在 Classroom 提交。如果愿意，可以先用自己的语言写，再翻译成意大利语。

A. 在 Classroom 打开作业

  1. 打开浏览器（Chrome）。在上方地址栏输入 classroom.google.com，按回车。
  2. 用学校账号登录。
  3. 点课程（班级）的方块。
  4. 在上方点 Lavori del corso（课业），再点作业 Ricerca: cos'è GitHub。

B. 创建文档

  1. 在右侧 Il tuo lavoro（你的作业）里，点 + Aggiungi o crea（添加或创建）。
  2. 点 Documenti Google（谷歌文档）：会打开一个文档。
  3. 在上方写标题：Cos'è GitHub。

C. 做研究（看和搜）

  1. 新开一个标签页，前往 github.com：看看网站是什么样。
  2. 再开一个标签页，前往 google.com，搜索：什么是 GitHub（可以用自己的语言搜）。
  3. 读 1–2 个简单的回答。

D. 把答案写进文档（写 4 句就够）

  1. 什么是 GitHub？（用一句话说它的用途）
  2. 什么是仓库（repository）？（一句话——它就像一个「项目文件夹」，里面有文件和它们的历史）
  3. 写一件你在 github.com 网站上看到的东西。
  4. 让它成为你的： 在 GitHub 上找一个你喜欢的项目或游戏，写下它的名字。
  5. 如果你用自己的语言写：去 translate.google.com，左边你的语言，右边意大利文，复制译文粘贴到文档里。

E. 提交作业

  1. 文档会自动保存。
  2. 回到 Classroom 的作业页面。
  3. 点蓝色的 Consegna（提交）按钮并确认 Consegna。完成！
在本子上（纸和笔）： 在电脑上写之前，先用手画一个小提纲写下你的答案。检验理解： 用你自己的话，口头向同学讲讲什么是 GitHub。
