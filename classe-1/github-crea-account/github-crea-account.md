# Crea il tuo account GitHub ed entra (prima lezione su Git)

**Versione 0.2** — 17/09/2026
*Scheda per gli allievi: creare l'account GitHub con l'email della scuola ed
entrare. A prova di errore, tutta da browser (nessuna installazione). Testo per
gli allievi: disponibile nelle 3 lingue nel PDF (`github-crea-account-v0.2.pdf`,
generato da `github-crea-account.html` per i font cinese e arabo). Questo `.md`
è la fonte (italiano). I bottoni dei siti sono indicati per posizione e colore
(non per solo testo inglese); gli indirizzi sono marcati "scrivilo così".*

---

## 1. GitHub è in inglese: rendilo italiano
1. Clicca con il tasto destro in un punto vuoto della pagina.
2. Clicca "Traduci in italiano" (Chrome traduce tutta la pagina).

## 2. Passi
1. Apri il browser (Chrome) e vai su questo indirizzo:

```
github.com
```

2. In alto a destra clicca il bottone per registrarti (di solito "Iscriviti" o
   "Registrati").
3. Scrivi la tua email della scuola (è un indirizzo, scrivilo esatto):

```
nome.cognome@studenti.piamarta.it
```

4. Clicca il bottone per andare avanti (di solito "Continua"), in basso nel
   riquadro.
5. Crea una password robusta (come abbiamo imparato) e clicca di nuovo avanti.
   Segnala in un posto sicuro.
6. Scegli il nome utente nella forma "nome-cognome" (se è già preso, aggiungi un
   numero) e clicca avanti.
7. Risolvi il piccolo gioco a immagini (dimostra che sei una persona).
8. Apri la tua email della scuola: trovi un codice da GitHub. Scrivilo dove
   richiesto per confermare.
9. Fatto: per entrare le prossime volte, su github.com clicca in alto a destra
   il bottone "Accedi" (in inglese "Sign in") e metti nome utente e password.

## 3. Mostralo / prova del nove
1. Quando sei entrato, sul quaderno scrivi a mano il tuo nome utente (non la
   password!) e racconta a voce al compagno cos'è GitHub.

## 4. Nota per il docente — DA PROVARE PRIMA
1. Prima di farlo con tutta la classe, prova con UN solo account (anche uno di
   test) e verifica: (1) che `github.com` non sia bloccato dal filtro della
   scuola; (2) che l'email di verifica di GitHub arrivi davvero sull'indirizzo
   `@studenti.piamarta.it` (molte scuole bloccano la posta esterna); (3) che la
   registrazione non sia impedita dalle policy.
2. Se qualcosa è bloccato: chiedere al sysadmin uno sblocco una tantum, oppure
   usare un'altra email.
3. Privacy: il nome utente su GitHub è pubblico; "nome-cognome" è riconoscibile
   ma espone il nome reale (per più privacy si può usare un soprannome). L'elenco
   di username/password degli allievi va tenuto fuori da GitHub e dal repository
   (dato personale di minori).
4. L'organizzazione della classe (repository, Classroom 50) si attiva quando
   arriva l'approvazione GitHub Education; creare l'account ed entrare è una
   prima lezione a sé.
