Crea il tuo account GitHub ed entra

Prima lezione su Git  ·  Italiano • العربية • 中文  ·  Classe 1
GitHub è in inglese. Fallo diventare italiano: clicca con il tasto destro in un punto vuoto della pagina, poi clicca Traduci in italiano. Da qui in poi vedrai tutto tradotto.

Passi (Italiano)

  1. Apri il browser (Chrome) e vai su questo indirizzo: github.com
  2. In alto a destra clicca Sign up (= Registrati).
  3. Scrivi la tua email della scuola: nome.cognome@studenti.piamarta.it e clicca Continue (= Continua).
  4. Crea una password robusta (come abbiamo imparato) e clicca Continue. Segnala in un posto sicuro.
  5. Scegli il nome utente nella forma nome-cognome (se è già preso, aggiungi un numero) e clicca Continue.
  6. Risolvi il piccolo gioco di verifica (immagini) che appare: serve a dimostrare che sei una persona.
  7. Apri la tua email della scuola: trovi un codice da GitHub. Scrivilo dove richiesto per confermare.
  8. Fatto: l'account è creato. Per entrare le prossime volte, su github.com clicca Sign in (= Accedi).
Mostralo / prova del nove: quando sei entrato, sul quaderno scrivi a mano il tuo nome utente (non la password!) e racconta a voce al compagno cos'è GitHub.

موقع GitHub بالإنجليزية. اجعله بالإيطالية: انقر بالزر الأيمن على مكان فارغ في الصفحة ثم اختر Traduci in italiano.

الخطوات:
١. افتح المتصفح (Chrome) واذهب إلى: github.com
٢. في الأعلى يمينًا انقر Sign up (= سجِّل).
٣. اكتب بريد المدرسة: nome.cognome@studenti.piamarta.it ثم Continue (= تابع).
٤. أنشئ كلمة مرور قوية ثم Continue. احفظها في مكان آمن.
٥. اختر اسم المستخدم بصيغة nome-cognome (إن كان محجوزًا أضف رقمًا) ثم Continue.
٦. حُلَّ لعبة التحقق بالصور التي تظهر (لإثبات أنك إنسان).
٧. افتح بريد المدرسة: ستجد رمزًا من GitHub. اكتبه لتأكيد الحساب.
٨. تمّ! للدخول لاحقًا، على github.com انقر Sign in (= دخول).

اعرضه: بعد الدخول، اكتب اسم المستخدم بخط يدك في الدفتر (وليس كلمة المرور!) واحكِ لزميلك ما هو GitHub.
创建你的 GitHub 账户并登录。
GitHub 是英文的。 把它变成意大利文：在页面空白处点右键，然后选 Traduci in italiano（翻译成意大利文）。

步骤：
1. 打开浏览器（Chrome），前往：github.com
2. 右上角点 Sign up（＝注册）。
3. 输入学校邮箱：nome.cognome@studenti.piamarta.it，点 Continue（＝继续）。
4. 创建一个安全的密码，点 Continue。把密码记在安全的地方。
5. 选用户名，格式 nome-cognome（若被占用就加个数字），点 Continue。
6. 完成出现的图片验证小游戏（证明你是真人）。
7. 打开学校邮箱：会收到 GitHub 的验证码，填进去确认。
8. 完成！以后登录：在 github.com 点 Sign in（＝登录）。

展示： 登录后，在本子上手写你的用户名（不要写密码！），并口头向同学说说 GitHub 是什么。
Nota per il docente — DA PROVARE PRIMA. Prima di farlo con tutta la classe, prova con UN solo account (anche il tuo di test) e verifica che: (1) la pagina github.com non sia bloccata dal filtro della scuola; (2) l'email di verifica di GitHub arrivi davvero sull'indirizzo @studenti.piamarta.it (molte scuole bloccano la posta esterna); (3) la registrazione non sia impedita dalle policy. Se qualcosa è bloccato, chiedere al sysadmin di sbloccarlo una tantum, oppure usare un'altra email.
Privacy: il nome utente su GitHub è pubblico; la forma nome-cognome è riconoscibile ma espone il nome reale (per più privacy: un soprannome). Tieni l'elenco di username/password degli allievi fuori da GitHub e dal repository (dato personale di minori). L'organizzazione della classe (repository, Classroom 50) si attiva quando arriva l'approvazione GitHub Education; creare l'account ed entrare è una prima lezione a sé.
