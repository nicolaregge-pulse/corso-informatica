电脑标准与配置

一年级 · 信息技术 · 图形按真实比例绘制 · 产品型号和缩写（ATX、PCIe、DDR5、Intel 等）保留拉丁字母

本课核心思想。 电脑内部的零件必须互相匹配：主板只能装进某些机箱，CPU 只能装进特定的插座（socket），内存只能插进它专用的插槽。为了让它们都能匹配，全世界统一了共同的尺寸和形状：这就是标准。今天看四个最重要的：主板尺寸（form factor）、PCIe 插槽、CPU 的插座（socket）、内存类型。
纸和笔。 看屏幕之前，每个人先在笔记本上手绘一个"主板"长方形，标出：CPU 装在哪里（socket）、内存装在哪里（又长又窄的插槽）、显卡装在哪里（PCIe x16 插槽）。最后和真实的对照一下。

1. 主板尺寸（Form factor）

Form factor = 主板的标准尺寸。它也决定需要哪种机箱：大主板装不进小机箱，小主板可以装进大机箱。

图 1 — 按比例绘制的三种尺寸对比。主板越大，插槽和接口越多。
名称尺寸插槽 / 扩展用途 — 产品型号
ATX305 × 244 mm多（4 内存，多 PCIe）最常见。台式机和游戏电脑。如 ASUS、MSI、Gigabyte 的 ATX 主板
microATX244 × 244 mm中等（2–4 内存）小型、经济型电脑，办公
Mini-ITX170 × 170 mm少（2 内存，1 PCIe）迷你电脑、客厅电脑（HTPC）
E-ATX305 × 330 mm非常多工作站和高端电脑
AT / Baby-AT老式—旧 IBM 标准，已停产（仅作常识）
要记住：ATX 是"标准"款；其它是它的变化版本。越小 = 空间越少 = 插槽越少。

2. PCIe 插槽 — 插扩展卡的地方

PCIe（PCI Express）是插扩展卡的插槽，最主要的是显卡（GPU）。数字（x1、x4、x8、x16）表示有多少条"通道"（数据线）：通道越多越快。短卡也能插进长插槽。

图 2 — 四种 PCIe 插槽的真实比例（89 / 56 / 39 / 25 mm）。
插槽通道用途（常见型号）
PCIe x1616显卡（NVIDIA GeForce、AMD Radeon）
PCIe x88RAID 卡、高速网卡、第二块显卡
PCIe x44NVMe 固态硬盘转接卡、控制器
PCIe x11网卡、声卡、USB、采集卡
PCIe 版本（速度）。 除了长度还有代数：PCIe 3.0 → 4.0 → 5.0。每升一代带宽翻倍，但插槽形状不变（互相兼容）。M.2 是专给 NVMe 固态硬盘的小插槽：用 PCIe 通道，但形状独特。

3. 插座（Socket）— 放 CPU 的地方

插座（socket）是主板上放 CPU（处理器）的"底座"。每个插座有名字，只能装特定的 CPU。两大家族，有一个重要的物理区别：

图 3 — LGA（针脚在插座）对比 PGA（针脚在 CPU）。左上角的小三角是"第一针"，指示正确方向。
插座类型可装的 CPU（型号）
Intel LGA1700LGAIntel Core 12/13/14 代（i3 / i5 / i7 / i9）
Intel LGA1851LGAIntel Core Ultra（第二代）
AMD AM4PGAAMD Ryzen 1000 → 5000 系列
AMD AM5LGAAMD Ryzen 7000 和 9000 系列
Intel LGA4677 / AMD SP5LGA服务器和工作站（Xeon、EPYC）
注意别搞混。 名字里的数字（1700、1851、AM4…）和触点数量有关，不代表"有多强"。CPU 和主板要成对购买，确认插座相同。

4. 内存类型 — DDR3、DDR4、DDR5

内存（RAM）是工作记忆：插在 CPU 旁边长插槽里的"内存条"。每一代 — DDR3、DDR4、DDR5 — 的缺口（防呆口）位置都不同：所以不可能插错插槽。主板只支持一种代数。

图 4 — 三代台式机内存（DIMM）缺口位置不同，下面是笔记本的 SO-DIMM。
类型针脚（DIMM）电压常见速度 · 产品型号
DDR32401,5 VDDR3-1600（PC3-12800）— 老电脑
DDR42881,2 VDDR4-3200（PC4-25600）— 较新标准
DDR52881,1 VDDR5-5600 / 6000 — 现行。如 Corsair、Kingston、Crucial
SO-DIMM更短—同样名字 + "SO-DIMM"：笔记本内存
注意针脚。 DDR4 和 DDR5 都是 288 针，但缺口位置不同，主板只支持一种：不能互换。台式机内存（DIMM，长）和笔记本内存（SO-DIMM，短）不同。

5. 小结 — 什么必须和什么匹配

  1. 机箱 ⟷ 主板：相同的尺寸（ATX、microATX、Mini-ITX）。
  2. 主板 ⟷ CPU：相同的插座（LGA1700、AM5…）。
  3. 主板 ⟷ 内存：相同的代数（DDR4 配 DDR4，DDR5 配 DDR5）。
  4. 显卡 ⟷ 主板：PCIe x16 插槽。
检验（能讲出来）。 最后每个人用自己的话讲："为什么 AMD 的 CPU 不能装在 Intel 主板上？为什么 DDR5 插不进 DDR4 插槽？" 能讲清楚，就是真懂了。
