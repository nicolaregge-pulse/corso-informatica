Mastermind: il codice completo

1. Che cosa fa il programma

  1. Il computer pensa un codice nascosto di 4 cifre da 1 a 6 (anche con cifre uguali).
  2. Tu scrivi 4 cifre e premi Prova: il programma dice quante sono esatte (giuste al posto giusto) e quante spostate (giuste ma nel posto sbagliato).
  3. Conta i tentativi usati, scrive la storia nel Memo, dice BRAVO quando indovini e ricorda il record.

2. Come si prepara la finestra

  1. Menu Progetto → Nuovo progetto… → Applicazione → OK. Salvalo in Documenti, cartella mastermind.
  2. Palette Common Controls: clicca TPageControl e clicca nella Form1. Nell'Ispettore oggetti metti Align = alClient.
  3. Tasto destro sul PageControl → Aggiungi pagina, tre volte. Scegli ogni scheda e cambia Caption: Gioco, Regole, Record.
  4. Clicca la scheda Gioco. Palette Standard: metti Edit1 (TEdit), Button1 (Caption Prova), Button2 (Caption Nuova partita). Svuota il Text di Edit1.
  5. Sempre sulla scheda Gioco metti 3 etichette (A): Label1, Label5 (Caption Tentativi usati: 0), Label2. Poi un Memo1 (TMemo) grande; svuota Lines.
  6. Clicca la scheda Regole: metti Label3. Clicca la scheda Record: metti Label4.
  7. Premi F12 per il codice, cancella tutto e incolla il unit1.pas qui sotto. Salva (Ctrl+S) e premi F9: gioca!

5. Il file unit1.pas completo

unit Unit1;

{$mode objfpc}{$H+}

interface

uses
  Classes, SysUtils, Forms, Controls, Graphics, Dialogs, StdCtrls, ComCtrls;

type
  TForm1 = class(TForm)
    PageControl1: TPageControl;   // le schede
    TabSheet1: TTabSheet;         // scheda Gioco
    TabSheet2: TTabSheet;         // scheda Regole
    TabSheet3: TTabSheet;         // scheda Record
    Button1: TButton;             // Prova
    Button2: TButton;             // Nuova partita
    Edit1: TEdit;                 // il tuo tentativo
    Label1: TLabel;               // risultato del tentativo
    Label2: TLabel;               // il codice segreto (solo per provare)
    Label3: TLabel;               // le regole (scheda Regole)
    Label4: TLabel;               // il record (scheda Record)
    Label5: TLabel;               // contatore dei tentativi usati
    Memo1: TMemo;                 // la storia dei tentativi
    procedure Button1Click(Sender: TObject);
    procedure Button2Click(Sender: TObject);
    procedure FormCreate(Sender: TObject);
  private
    Segreto: String;              // il codice nascosto, per esempio '3162'
    Tentativi: Integer;           // quanti tentativi hai usato
    Record_: Integer;             // il minor numero di tentativi (0 = nessun record)
    Finita: Boolean;              // True quando hai indovinato
  public
  end;

var
  Form1: TForm1;

implementation

{$R *.lfm}

procedure TForm1.FormCreate(Sender: TObject);
begin
  Randomize;
  Record_ := 0;
  Edit1.MaxLength := 4;
  Label3.Caption := 'Il computer pensa 4 cifre da 1 a 6. ' +
    'Tu provi. "Esatte" = cifra giusta al posto giusto. ' +
    '"Spostate" = cifra giusta ma al posto sbagliato.';
  Label4.Caption := 'Record: nessuno (gioca una partita!)';
  Button2Click(Sender);              // comincia una partita nuova
end;

procedure TForm1.Button2Click(Sender: TObject);   // Nuova partita
var
  i: Integer;
begin
  Segreto := '';
  for i := 1 to 4 do
    Segreto := Segreto + IntToStr(Random(6) + 1);
  Tentativi := 0;
  Finita := False;
  Memo1.Clear;
  Edit1.Clear;
  Label2.Caption := 'Codice segreto: ' + Segreto;
  Label5.Caption := 'Tentativi usati: 0';
  Label1.Caption := 'Partita nuova: indovina le 4 cifre (da 1 a 6)';
end;

procedure TForm1.Button1Click(Sender: TObject);   // Prova
var
  i, j, esatte, spostate: Integer;
  tentativo: String;
  usataS, usataT: array[1..4] of Boolean;
begin
  if Finita then
  begin
    Label1.Caption := 'Hai gia vinto! Premi Nuova partita';
    Exit;
  end;
  tentativo := Edit1.Text;
  if Length(tentativo) <> 4 then
  begin
    Label1.Caption := 'Scrivi 4 cifre!';
    Exit;
  end;
  for i := 1 to 4 do
    if (tentativo[i] < '1') or (tentativo[i] > '6') then
    begin
      Label1.Caption := 'Usa solo cifre da 1 a 6!';
      Exit;
    end;
  Tentativi := Tentativi + 1;
  Label5.Caption := 'Tentativi usati: ' + IntToStr(Tentativi);
  for i := 1 to 4 do
  begin
    usataS[i] := False;
    usataT[i] := False;
  end;
  esatte := 0;
  for i := 1 to 4 do                      // prima le esatte
    if tentativo[i] = Segreto[i] then
    begin
      esatte := esatte + 1;
      usataS[i] := True;
      usataT[i] := True;
    end;
  spostate := 0;
  for i := 1 to 4 do                      // poi le spostate
    if not usataT[i] then
      for j := 1 to 4 do
        if (not usataS[j]) and (tentativo[i] = Segreto[j]) then
        begin
          spostate := spostate + 1;
          usataS[j] := True;
          Break;
        end;
  Memo1.Lines.Add(IntToStr(Tentativi) + ') ' + tentativo + ' -> esatte: ' +
    IntToStr(esatte) + '  spostate: ' + IntToStr(spostate));
  if esatte = 4 then
  begin
    Finita := True;
    Label1.Caption := 'BRAVO! Indovinato in ' + IntToStr(Tentativi) + ' tentativi';
    if (Record_ = 0) or (Tentativi < Record_) then
    begin
      Record_ := Tentativi;
      Label4.Caption := 'Record: ' + IntToStr(Record_) + ' tentativi';
    end;
  end
  else
    Label1.Caption := 'Esatte: ' + IntToStr(esatte) + '  Spostate: ' + IntToStr(spostate);
  Edit1.Clear;
end;

end.

6. Come si legge il codice

  1. FormCreate: parte una volta sola quando si apre la finestra: accende Randomize, scrive le regole, azzera il record e comincia la prima partita.
  2. Button2Click (Nuova partita): crea 4 cifre a caso da 1 a 6, azzera i tentativi, svuota il Memo e la casella.
  3. Button1Click (Prova): controlla il tentativo: deve avere 4 cifre da 1 a 6, aumenta il contatore e scrive il risultato.
  4. ciclo delle esatte (dentro Prova): confronta cifra per cifra: stessa cifra e stesso posto = esatta.
  5. ciclo delle spostate (dentro Prova): per le cifre rimaste cerca la stessa cifra in un altro posto, senza usare due volte la stessa: così i doppioni funzionano.
  6. vittoria (dentro Prova): se le esatte sono 4 scrive BRAVO con il numero di tentativi e aggiorna il record se è il migliore.

Prova da solo prima di copiare. Poi racconta a voce, con parole tue, che cosa fa ogni pezzo: è la prova che hai capito.
