2. Il protocollo in breve

Una riga per messaggio, campi separati da ;. Rete: il client si collega, manda UNA riga, legge UNA riga, chiude. Dettaglio completo in protocollo.md.

DirezioneRigaSignificato
client → serverGUESS;NOME;1234un tentativo
client → serverSTATO;NOMEsolo aggiornare la console
server → clientRESULT;esatte;spostate;tentativi;posizione;totale;migliore;peggioretentativo sbagliato
server → clientWIN;NOME;tentativi;secondi;posizione;totale;migliore;peggioreindovinato (al posto di RESULT)
server → clientWAITil prof non ha ancora dato il Via
server → clientERR;motivoriga sbagliata

Posizione = il tuo posto tra chi ha indovinato (0 = non ancora). Ordine: meno tentativi, poi meno secondi dal Via; stessi tentativi e secondi = pari merito (1, 2, 2, 4). Migliore / peggiore = tentativi del migliore e del peggiore tra chi ha finito. I secondi li misura il server.

EsempioRiga
tentativo sbagliatoGUESS;Sara M.;1234 → RESULT;1;2;1;0;0;0;0
indovinatoGUESS;Sara M.;4162 → WIN;Sara M.;2;85;3;5;1;4
prima del ViaGUESS;Sara M.;1111 → WAIT

Limite del modo file con GitHub. Studente: Commit + Push · prof: Pull · il server aggiorna · prof: Commit + Push di ranking.txt · studente: Pull. Ritardo di almeno un minuto: è il piano di riserva, NON si gioca dal vivo così. Con una cartella di rete il ritardo è di pochi secondi. Inoltre nel modo file il codice si ricava dal seme (un ragazzo bravo potrebbe leggerlo): il server ricalcola comunque ogni tentativo.

3.5 Esempio di ip-nomi.txt (dati inventati)

Una riga per PC: IP;NOME. Le righe che cominciano con # sono commenti. Con questo file il nome in classifica è quello scritto qui, anche se il ragazzo scrive un altro nome.

192.168.10.23;Carla G.

Il server prende il nome dall'IP di chi si collega; per un IP che non c'è nella lista vale il nome scritto dal client. Attenzione: serve che la lista sia degli IP dei PC, non delle persone (se un ragazzo cambia PC cambia nome in classifica).

5. Che cosa è stato provato davvero e che cosa no

Provato con fpc 3.2.2 (Linux), tutto passato: 104 prove automatiche. 1) la logica pura con orologio finto (conteggio esatte/spostate, WAIT prima del Via, tentativo giusto e sbagliato, classifica con pari merito, migliore e peggiore, chi arriva tardi, nuova partita, IP→nome); 2) il trasporto a file con server e 5 client sulla stessa cartella (righe di partite vecchie, riga a metà, nessun conteggio doppio, file di configurazione); 3) la rete TCP su localhost con il VERO server_mastermind e client simulati (anche con richieste in un thread, riga senza senso, client muto, passaggio automatico ai file, nome preso dall'IP); 4) la scheda dello studente (unit1_client.pas) compila contro finte unità LCL.
NON provato: 1) le vere finestre LCL di Lazarus (la scheda dello studente è stata compilata solo contro finte unità: sintassi e tipi, non il comportamento a schermo); 2) il server e i client su Windows (provato solo su Linux; il codice usa solo ssockets e sockets che esistono anche su Windows); 3) il firewall e la rete reali della scuola; 4) la tastiera Crt sulla console di Windows (provata solo su una console Linux); 5) il lavoro con GitHub Desktop; 6) 14 PC insieme (provate poche connessioni simultanee). Non è stato usato lNet, né Indy, né Synapse: solo ssockets, che è già dentro Free Pascal/Lazarus (nessun pacchetto da installare, nessuna ricostruzione dell'IDE). La rete gira in un thread (TThread), così la finestra non si blocca.

Consiglio: prima di usarlo con i ragazzi, 10 minuti di prova con due PC della scuola (server + un client).

6. Il codice completo

unit mm_logica;
{ MASTERMIND 2.0 - LOGICA (nessuna finestra, nessuna rete).
  Qui c'e' il cervello: il codice segreto, il conteggio esatte/spostate,

  Si puo' provare da solo, senza Lazarus e senza rete. }

{$mode objfpc}{$H+}

interface

uses
  SysUtils, Classes;

type
  TFase = (faAttesa, faGioco);
  TEsito = (esAttesa, esNonValido, esOk, esVinto, esGiaVinto);

  { Quello che serve alla "console" dello studente }

{ Il campo numero N (da 1) di una riga separata da punti e virgola }
function Campo(const Linea: String; N: Integer): String;
var
  i, k, ini: Integer;
begin
  Result := '';
  k := 1;
  ini := 1;
  for i := 1 to Length(Linea) + 1 do
    if (i > Length(Linea)) or (Linea[i] = ';') then
    begin
      if k = N then
      begin
        Result := Copy(Linea, ini, i - ini);
        Exit;
      end;
      k := k + 1;
      ini := i + 1;
    end;
end;

{ Da un numero (seme) esce sempre lo stesso codice: cosi' server e client
  del piano B (file) possono avere lo stesso codice senza parlarsi. }
function CodiceDaSeme(ASeme: Int64): String;
var
  x: Int64;
  i: Integer;
begin
  x := ASeme and $7FFFFFFF;
  Result := '';
  for i := 1 to 4 do
  begin
    x := (x * 1103515245 + 12345) and $7FFFFFFF;
    Result := Result + IntToStr(((x shr 16) mod 6) + 1);
  end;
end;

{ Stessa logica del Mastermind normale: prima le esatte, poi le spostate }
procedure Valuta(const Segreto, Tent: String; out Esatte, Spostate: Integer);
var
  i, j: Integer;
  usataS, usataT: array[1..4] of Boolean;
begin
  for i := 1 to 4 do
  begin
    usataS[i] := False;
    usataT[i] := False;
  end;
  Esatte := 0;
  for i := 1 to 4 do
    if Tent[i] = Segreto[i] then
    begin
      Esatte := Esatte + 1;
      usataS[i] := True;
      usataT[i] := True;
    end;
  Spostate := 0;
  for i := 1 to 4 do
    if not usataT[i] then
      for j := 1 to 4 do
        if (not usataS[j]) and (Tent[i] = Segreto[j]) then
        begin
          Spostate := Spostate + 1;
          usataS[j] := True;
          Break;
        end;
end;

function CodiceValido(const S: String): Boolean;
var
  i: Integer;
begin
  Result := Length(S) = 4;
  if Result then
    for i := 1 to 4 do
      if not (S[i] in ['1'..'6']) then
        Result := False;
end;

{ Toglie ; e caratteri strani dal nome (il ; separa i campi!), max 20 }
function PulisciNome(const S: String): String;
var
  i: Integer;
begin
  Result := '';
  for i := 1 to Length(S) do
    if (S[i] >= ' ') and not (S[i] in [';', '/', '\', ':', '*', '?', '"', '<', '>', '|']) then
      Result := Result + S[i];
  Result := Trim(Result);
  if Length(Result) > 20 then
    Result := Trim(Copy(Result, 1, 20));
end;

function SIntero(const S: String; Pred: Integer = 0): Integer;
begin
  Result := StrToIntDef(Trim(S), Pred);
end;

{ Chi e' meglio di G? Meglio = piu' risolti, a parita' meno tentativi, poi meno secondi.
  La posizione e' 1 + il numero di chi ha finito ed e' STRETTAMENTE meglio.
  Pari tentativi e pari secondi = stessa posizione (parimerito). }
function TMMTabella.PosizioneDi(G: TGiocatore): Integer;
var
  i: Integer;
  H: TGiocatore;
begin
  Result := 0;
  if not G.Risolto then Exit;
  Result := 1;
  for i := 0 to FGiocatori.Count - 1 do
  begin
    H := TGiocatore(FGiocatori[i]);
    if H.Risolto and ((H.Tentativi < G.Tentativi) or
       ((H.Tentativi = G.Tentativi) and (H.Secondi < G.Secondi))) then
      Result := Result + 1;
  end;
end;

function TMMTabella.Tentativo(const ANome, AGuess: String; ASecondiForzati: Integer;
  out Esatte, Spostate: Integer): TEsito;
var
  G: TGiocatore;
  nome: String;
begin
  Esatte := 0;
  Spostate := 0;
  nome := PulisciNome(ANome);
  if (nome = '') or not CodiceValido(AGuess) then
  begin
    Result := esNonValido;
    Exit;
  end;
  if FFase = faAttesa then
  begin
    Result := esAttesa;
    Exit;
  end;
  G := Cerca(nome);
  if G = nil then G := Crea(nome);
  Valuta(FSegreto, AGuess, Esatte, Spostate);
  if G.Risolto then
  begin
    Result := esGiaVinto;     // non conta piu': il risultato resta quello di prima
    Exit;
  end;
  G.Tentativi := G.Tentativi + 1;
  if Esatte = 4 then
  begin
    G.Risolto := True;
    if ASecondiForzati >= 0 then
      G.Secondi := ASecondiForzati
    else
      G.Secondi := Round(Orologio() - FViaOra);
    Result := esVinto;
  end
  else
    Result := esOk;
end;

function TMMTabella.SintesiDi(const ANome: String): TSintesi;
var
  i: Integer;
  G, H: TGiocatore;
begin
  Result.Tentativi := 0;
  Result.Posizione := 0;
  Result.Totale := 0;
  Result.Migliore := 0;
  Result.Peggiore := 0;
  for i := 0 to FGiocatori.Count - 1 do
  begin
    H := TGiocatore(FGiocatori[i]);
    if H.Risolto then
    begin
      Result.Totale := Result.Totale + 1;
      if (Result.Migliore = 0) or (H.Tentativi < Result.Migliore) then
        Result.Migliore := H.Tentativi;
      if H.Tentativi > Result.Peggiore then
        Result.Peggiore := H.Tentativi;
    end;
  end;
  G := Cerca(PulisciNome(ANome));
  if G <> nil then
  begin
    Result.Tentativi := G.Tentativi;
    Result.Posizione := PosizioneDi(G);
  end;
end;

function SintesiTesto(const S: TSintesi): String;
begin
  Result := IntToStr(S.Tentativi) + ';' + IntToStr(S.Posizione) + ';' +
    IntToStr(S.Totale) + ';' + IntToStr(S.Migliore) + ';' + IntToStr(S.Peggiore);
end;

{ IL PROTOCOLLO A RIGHE (vedi protocollo.md). Riceve UNA riga, restituisce UNA riga. }
function TMMTabella.Gestisci(const Linea: String; const IpClient: String): String;
var
  cmd, nome, guess: String;
  esa, spo: Integer;
  S: TSintesi;
  G: TGiocatore;
begin
  cmd := UpperCase(Trim(Campo(Linea, 1)));
  nome := PulisciNome(Campo(Linea, 2));
  if (IpClient <> '') and (NomePerIp(IpClient) <> '') then
    nome := NomePerIp(IpClient);        // IP noto: vale il nome della tabella, non quello scritto dal client
  if cmd = 'GUESS' then
  begin
    guess := Trim(Campo(Linea, 3));
    case Tentativo(nome, guess, -1, esa, spo) of
      esAttesa: Result := 'WAIT';
      esNonValido:
        if nome = '' then Result := 'ERR;nome non valido'
        else Result := 'ERR;codice non valido (servono 4 cifre da 1 a 6)';
      esOk:
        begin
          S := SintesiDi(nome);
          Result := 'RESULT;' + IntToStr(esa) + ';' + IntToStr(spo) + ';' + SintesiTesto(S);
        end;
      esVinto, esGiaVinto:
        begin
          S := SintesiDi(nome);
          G := Cerca(nome);
          Result := 'WIN;' + nome + ';' + IntToStr(G.Tentativi) + ';' + IntToStr(G.Secondi) +
            ';' + IntToStr(S.Posizione) + ';' + IntToStr(S.Totale) + ';' +
            IntToStr(S.Migliore) + ';' + IntToStr(S.Peggiore);
        end;
    end;
  end
  else if cmd = 'STATO' then
  begin
    S := SintesiDi(nome);
    if FFase = faAttesa then Result := 'STATO;ATTESA;' else Result := 'STATO;GIOCO;';
    Result := Result + SintesiTesto(S);
  end
  else
    Result := 'ERR;comando sconosciuto';
end;

procedure TMMTabella.CaricaIpNomi(const Testo: String);
var
  L: TStringList;
  i: Integer;
  ip, nm: String;
begin
  IpNomi.Clear;
  L := TStringList.Create;
  try
    L.Text := Testo;
    for i := 0 to L.Count - 1 do
    begin
      ip := Trim(Campo(L[i], 1));
      nm := PulisciNome(Campo(L[i], 2));
      if (ip <> '') and (ip[1] <> '#') and (nm <> '') then
        IpNomi.Add(ip + '=' + nm);
    end;
  finally
    L.Free;
  end;
end;

function TMMTabella.NomePerIp(const Ip: String): String;
begin
  Result := IpNomi.Values[Trim(Ip)];
end;

function TMMTabella.TestoPresenze: String;
var
  i: Integer;
  nm, st: String;
  G: TGiocatore;
  nessuno: Boolean;
begin
  Result := 'CHI HA GIA'' PROVATO / CHI NO (dalla lista ip-nomi.txt)' + LineEnding;
  nessuno := True;
  for i := 0 to IpNomi.Count - 1 do
  begin
    nm := IpNomi.ValueFromIndex[i];
    G := Cerca(nm);
    if G = nil then st := 'NON ha ancora provato'
    else if G.Risolto then st := 'ha indovinato (' + IntToStr(G.Tentativi) + ' tentativi)'
    else st := 'sta provando (' + IntToStr(G.Tentativi) + ' tentativi)';
    Result := Result + Format('  %-16s %-20s %s', [IpNomi.Names[i], nm, st]) + LineEnding;
    nessuno := False;
  end;
  if nessuno then Result := Result + '  (nessun file ip-nomi.txt: si usano i nomi scritti dai ragazzi)' + LineEnding;
end;

function TMMTabella.TestoClassifica: String;
var
  i, k, pos, n: Integer;
  lista: TList;
  G, H: TGiocatore;
  S: TSintesi;
  rig: String;
begin
  lista := TList.Create;
  try
    for i := 0 to FGiocatori.Count - 1 do lista.Add(FGiocatori[i]);
    // ordinamento a bolle: risolti prima, poi tentativi, poi secondi
    for i := 0 to lista.Count - 2 do
      for k := 0 to lista.Count - 2 - i do
      begin
        G := TGiocatore(lista[k]);
        H := TGiocatore(lista[k + 1]);
        if (H.Risolto and not G.Risolto) or
           ((H.Risolto = G.Risolto) and ((H.Tentativi < G.Tentativi) or
           ((H.Tentativi = G.Tentativi) and H.Risolto and (H.Secondi < G.Secondi)))) then
          lista.Exchange(k, k + 1);
      end;
    S := SintesiDi('');
    if FFase = faAttesa then rig := 'IN ATTESA DEL VIA' else rig := 'IN GIOCO';
    Result := 'PARTITA ' + FIdPartita + ' - ' + rig + ' - finiti: ' + IntToStr(S.Totale) +
      ' di ' + IntToStr(FGiocatori.Count) + ' - migliore: ' + IntToStr(S.Migliore) +
      ' - peggiore: ' + IntToStr(S.Peggiore) + LineEnding;
    Result := Result + ' Pos  Nome                  Tentativi  Secondi  Stato' + LineEnding;
    n := 0;
    for i := 0 to lista.Count - 1 do
    begin
      G := TGiocatore(lista[i]);
      pos := PosizioneDi(G);
      if pos > 0 then rig := IntToStr(pos) else rig := '-';
      Result := Result + Format(' %3s  %-20s  %9d  %7s  %s', [rig, G.Nome, G.Tentativi,
        BoolToStr(G.Risolto, IntToStr(G.Secondi), '-'),
        BoolToStr(G.Risolto, 'INDOVINATO', 'sta provando')]) + LineEnding;
      n := n + 1;
    end;
    if n = 0 then Result := Result + ' (nessuno ha ancora provato)' + LineEnding;
  finally
    lista.Free;
  end;
end;

function ParsaRisposta(const Linea: String; out R: TRisposta): Boolean;
var
  cmd: String;
begin
  FillChar(R, SizeOf(R), 0);
  R.Tipo := '';
  R.Messaggio := '';
  cmd := UpperCase(Trim(Campo(Linea, 1)));
  Result := True;
  if cmd = 'RESULT' then
  begin
    R.Tipo := 'RESULT';
    R.Esatte := SIntero(Campo(Linea, 2));
    R.Spostate := SIntero(Campo(Linea, 3));
    R.Sintesi.Tentativi := SIntero(Campo(Linea, 4));
    R.Sintesi.Posizione := SIntero(Campo(Linea, 5));
    R.Sintesi.Totale := SIntero(Campo(Linea, 6));
    R.Sintesi.Migliore := SIntero(Campo(Linea, 7));
    R.Sintesi.Peggiore := SIntero(Campo(Linea, 8));
  end
  else if cmd = 'WIN' then
  begin
    R.Tipo := 'WIN';
    R.Esatte := 4;
    R.Sintesi.Tentativi := SIntero(Campo(Linea, 3));
    R.Secondi := SIntero(Campo(Linea, 4));
    R.Sintesi.Posizione := SIntero(Campo(Linea, 5));
    R.Sintesi.Totale := SIntero(Campo(Linea, 6));
    R.Sintesi.Migliore := SIntero(Campo(Linea, 7));
    R.Sintesi.Peggiore := SIntero(Campo(Linea, 8));
  end
  else if cmd = 'WAIT' then
    R.Tipo := 'WAIT'
  else if cmd = 'STATO' then
  begin
    R.Tipo := 'STATO';
    R.Messaggio := Campo(Linea, 2);          // ATTESA o GIOCO
    R.Sintesi.Tentativi := SIntero(Campo(Linea, 3));
    R.Sintesi.Posizione := SIntero(Campo(Linea, 4));
    R.Sintesi.Totale := SIntero(Campo(Linea, 5));
    R.Sintesi.Migliore := SIntero(Campo(Linea, 6));
    R.Sintesi.Peggiore := SIntero(Campo(Linea, 7));
  end
  else if cmd = 'ERR' then
  begin
    R.Tipo := 'ERR';
    R.Messaggio := Campo(Linea, 2);
  end
  else
  begin
    R.Tipo := 'ERR';
    R.Messaggio := 'risposta non capita';
    Result := False;
  end;
end;

{ Legge ranking.txt (piano B): tira fuori la sintesi per il nome dato }
function SintesiDaRanking(const Testo, ANome: String; out Fase: TFase;
  out Id: String; out Seme: Int64): TSintesi;
var
  L: TStringList;
  i, pos, num: Integer;
  riga, nome: String;
  mio: Boolean;
begin
  FillChar(Result, SizeOf(Result), 0);
  Fase := faAttesa;
  Id := '';
  Seme := 0;
  nome := PulisciNome(ANome);
  L := TStringList.Create;
  try
    L.Text := Testo;
    for i := 0 to L.Count - 1 do
    begin
      riga := Trim(L[i]);
      if Copy(riga, 1, 8) = 'PARTITA;' then
      begin
        Id := Campo(riga, 2);
        if Campo(riga, 3) <> '' then Seme := StrToInt64Def(Campo(riga, 3), 0);
        if Campo(riga, 4) = 'GIOCO' then Fase := faGioco;      // forma di partita.txt
      end
      else if riga = 'STATO;GIOCO' then Fase := faGioco
      else if Copy(riga, 1, 7) = 'TOTALE;' then Result.Totale := SIntero(Campo(riga, 2))
      else if Copy(riga, 1, 9) = 'MIGLIORE;' then Result.Migliore := SIntero(Campo(riga, 2))
      else if Copy(riga, 1, 9) = 'PEGGIORE;' then Result.Peggiore := SIntero(Campo(riga, 2))
      else if Copy(riga, 1, 2) = 'R;' then
      begin
        pos := SIntero(Campo(riga, 2));
        mio := SameText(Campo(riga, 3), nome);
        num := SIntero(Campo(riga, 4));
        if mio then
        begin
          Result.Tentativi := num;
          Result.Posizione := pos;
        end;
      end;
    end;
  finally
    L.Free;

  TMMRichiestaAsync = class(TThread)

    FLinea: String;

  protected
    procedure Execute; override;

constructor TMMTcpServerThread.Create(ATabella: TMMTabella; APorta: Word);
begin
  FTabella := ATabella;
  FPorta := APorta;
  FreeOnTerminate := False;
  inherited Create(False);
end;

procedure TMMTcpServerThread.Connesso(Sender: TObject; Data: TSocketStream);
var
  c: Char;
  n: Integer;
  linea, risp: String;
begin
  try
    try
      Data.IOTimeout := 2000;           // un client muto non blocca il server
      linea := '';
      repeat
        n := Data.Read(c, 1);
        if (n = 1) and (c <> #10) and (c <> #13) then linea := linea + c;
      until (n <= 0) or (c = #10) or (Length(linea) > 200);
      if linea <> '' then
      begin
        FTabella.Blocca;
        try
          risp := FTabella.Gestisci(linea, NetAddrToStr(Data.RemoteAddress.sin_addr));
        finally
          FTabella.Sblocca;
        end;
        risp := risp + #10;
        Data.WriteBuffer(risp[1], Length(risp));
      end;
    except
      on E: Exception do ;               // un client che sbaglia non deve fermare il server
    end;
  finally
    Data.Free;
  end;
end;

procedure TMMTcpServerThread.Inattivo(Sender: TObject);
begin
  if Terminated then FServer.StopAccepting;
end;

procedure TMMTcpServerThread.Execute;
begin
  Errore := '';
  FServer := nil;
  try
    FServer := TInetServer.Create('0.0.0.0', FPorta);
    {$ifdef unix}FServer.ReuseAddress := True;{$endif}   // riavvio veloce senza "porta occupata"
    FServer.AcceptIdleTimeout := 250;    // ogni 1/4 di secondo controlla se deve fermarsi
    FServer.OnConnect := @Connesso;
    FServer.OnIdle := @Inattivo;
    Pronto := True;
    FServer.StartAccepting;              // resta qui finche' non arriva StopAccepting
  except
    on E: Exception do
    begin
      Errore := E.Message;
      Pronto := False;
    end;
  end;
  FServer.Free;
end;

function MMTcpRichiesta(const Host: String; Porta: Word; const Linea: String;
  TimeoutMs: Integer): String;
var
  S: TInetSocket;
  c: Char;
  n: Integer;
  riga: String;
begin
  Result := '';
  try
    S := TInetSocket.Create(Host, Porta, TimeoutMs);
    try
      S.IOTimeout := TimeoutMs;
      riga := Linea + #10;
      S.WriteBuffer(riga[1], Length(riga));
      repeat
        n := S.Read(c, 1);
        if (n = 1) and (c <> #10) and (c <> #13) then Result := Result + c;
      until (n <= 0) or (c = #10) or (Length(Result) > 300);
    finally
      S.Free;
    end;
    if Result = '' then Result := 'ERR;nessuna risposta dal server';
  except
    on E: Exception do
      Result := 'ERR;server non raggiungibile (' + E.Message + ')';
  end;
end;

  const ALinea: String; AlFinire: TNotifyEvent);

end;

  Synchronize(@Fine);
end;

function TMMClient.ProvaFile(const Tent: String): TRisposta;
var
  base, testoP, testoR, mio, riga, segreto, id, tutto: String;
  seme, via: Int64;
  fase: TFase;
  sint: TSintesi;
  righe: TStringList;
  i, mie, ultimoSec, esa, spo, sec: Integer;
  risolto: Boolean;
begin
  Result := Default(TRisposta);
  base := IncludeTrailingPathDelimiter(Cartella);
  if not CodiceValido(Trim(Tent)) then
  begin
    Result.Tipo := 'ERR';
    Result.Messaggio := 'codice non valido (servono 4 cifre da 1 a 6)';
    Exit;
  end;
  if (PulisciNome(Nome) = '') then
  begin
    Result.Tipo := 'ERR';
    Result.Messaggio := 'scrivi il tuo nome';
    Exit;
  end;
  if not MMLeggiTesto(base + 'partita.txt', testoP) then
  begin
    Result.Tipo := 'ERR';
    Result.Messaggio := 'non trovo partita.txt nella cartella (sincronizza o controlla il percorso)';
    Exit;
  end;
  // partita.txt ha la stessa forma di una riga PARTITA di ranking.txt
  sint := SintesiDaRanking(testoP, Nome, fase, id, seme);
  if (fase <> faGioco) or (seme = 0) then
  begin
    Result.Tipo := 'WAIT';
    Exit;
  end;
  segreto := CodiceDaSeme(seme);
  mio := MMFileGiocatore(Cartella, Nome);
  // rileggo il MIO file: quanti tentativi ho fatto in questa partita? ho gia' vinto?
  mie := 0;
  ultimoSec := 0;
  risolto := False;
  righe := TStringList.Create;
  try
    if MMLeggiTesto(mio, tutto) then righe.Text := tutto;
    for i := 0 to righe.Count - 1 do
    begin
      riga := Trim(righe[i]);
      if Campo(riga, 1) = id then
      begin
        mie := mie + 1;
        ultimoSec := StrToIntDef(Campo(riga, 4), 0);
        if Campo(riga, 3) = segreto then risolto := True;
      end;
    end;
  finally
    righe.Free;
  end;
  // lo "zero" del tempo: il Via scritto dal server in partita.txt
  if FIdVisto <> id then
  begin
    FIdVisto := id;
    via := StrToInt64Def(Campo(Trim(testoP), 5), 0);      // ora del Via secondo il server
    if (via > 0) and (Orologio() - via >= 0) and (Orologio() - via < 14400) then
      FZero := via                                        // orologi d'accordo: conta dal Via vero
    else
      FZero := Orologio() - ultimoSec;                    // orologi sballati: conta da quando lo vedo io
  end;
  sec := Round(Orologio() - FZero);
  Valuta(segreto, Trim(Tent), esa, spo);
  if not risolto then
  begin
    MMAggiungiRiga(mio, id + ';' + PulisciNome(Nome) + ';' + Trim(Tent) + ';' + IntToStr(sec));
    mie := mie + 1;
    risolto := (esa = 4);
  end
  else
  begin
    esa := 4;      // ha gia' vinto: i tentativi in piu' non contano
    spo := 0;
  end;
  // la classifica la vedo da ranking.txt (puo' essere in ritardo)
  sint := Default(TSintesi);
  if MMLeggiTesto(base + 'ranking.txt', testoR) then
    sint := SintesiDaRanking(testoR, Nome, fase, id, seme);
  sint.Tentativi := mie;
  if not risolto then sint.Posizione := 0;
  Result.Esatte := esa;
  Result.Spostate := spo;
  Result.Sintesi := sint;
  if risolto then
  begin
    Result.Tipo := 'WIN';
    Result.Secondi := sec;
  end
  else
    Result.Tipo := 'RESULT';
  Ultima := sint;
end;

uses

    Label3: TLabel;               // le regole (scheda Regole)

  Form1: TForm1;

{$R *.lfm}

procedure TForm1.FormCreate(Sender: TObject);
begin
  Label3.Caption := 'Il server del prof pensa 4 cifre da 1 a 6, uguali per tutti. ' +
    'Tu provi. "Esatte" = cifra giusta al posto giusto. ' +
    '"Spostate" = cifra giusta ma al posto sbagliato. Vince chi usa meno tentativi.';
  Label4.Caption := 'Scrivi il tuo nome e aspetta il Via del prof';
  Cl := TMMClient.Create;
  // legge server.txt (IP:PORTA) e/o cartella.txt accanto al programma
  if not Cl.CaricaConfig(ExtractFilePath(Application.ExeName)) then
    Label1.Caption := 'Manca il file server.txt o cartella.txt accanto al programma';
  Label2.Caption := 'Codice segreto: ????';
  Orologio3s := TTimer.Create(Self);        // il timer nasce qui, non serve metterlo sulla Form
  Orologio3s.Interval := 3000;
  Orologio3s.OnTimer := @Timer1Timer;
  Orologio3s.Enabled := True;
end;

procedure TForm1.Button2Click(Sender: TObject);   // Nuova partita
begin
  Label1.Caption := 'La nuova partita la fa partire il prof';
end;

{ Scrive nel Label1 e nel Memo cosa e' successo }
procedure TForm1.MostraEsito(const R: TRisposta; const Tent: String);
begin
  Label1.Caption := Cl.TestoRisposta(R);
  if (R.Tipo = 'RESULT') or (R.Tipo = 'WIN') then
    Memo1.Lines.Add(IntToStr(R.Sintesi.Tentativi) + ') ' + Tent + ' -> esatte: ' +
      IntToStr(R.Esatte) + '  spostate: ' + IntToStr(R.Spostate));
  Label4.Caption := Cl.Console;
end;

procedure TForm1.Button1Click(Sender: TObject);   // Prova
begin
  Cl.Nome := Edit2.Text;
  UltimoTentativo := Edit1.Text;
  if Length(UltimoTentativo) <> 4 then
  begin
    Label1.Caption := 'Scrivi 4 cifre!';
    Exit;
  end;
  if Cl.Modo = moRete then
  begin
    Label1.Caption := 'Invio al server...';
    // la richiesta parte in un THREAD: la finestra non si blocca
    TMMRichiestaAsync.Create(Cl.Host, Cl.Porta, Cl.RigaProva(UltimoTentativo), @RispostaTentativo);
  end
  else
    MostraEsito(Cl.Prova(UltimoTentativo), UltimoTentativo);   // i file sono veloci
  Edit1.Clear;
end;

procedure TForm1.RispostaTentativo(Sender: TObject);   // chiamata quando il server ha risposto
var
  testo: String;
begin
  testo := TMMRichiestaAsync(Sender).Risposta;
  MostraEsito(Cl.RispostaDaRete(testo, UltimoTentativo), UltimoTentativo);
end;

procedure TForm1.RispostaStato(Sender: TObject);
begin
  Cl.ApplicaRisposta(TMMRichiestaAsync(Sender).Risposta);
  Label4.Caption := Cl.Console;
end;

procedure TForm1.Timer1Timer(Sender: TObject);   // ogni 3 secondi
begin
  Cl.Nome := Edit2.Text;
  if Cl.Nome = '' then Exit;
  if Cl.Modo = moRete then
    TMMRichiestaAsync.Create(Cl.Host, Cl.Porta, Cl.RigaStato, @RispostaStato)
  else
  begin
    Cl.Aggiorna;
    Label4.Caption := Cl.Console;
  end;
end;

end.

program server_mastermind;
{ MASTERMIND 2.0 - SERVER (programma a console, gira sul PC del prof).
  Tasti:  V = Via!   N = Nuova partita (nuovo codice)   R = ridisegna
          I = rileggi ip-nomi.txt   Q = esci
  Opzioni (tutte facoltative), per esempio:  server_mastermind --porta=5050 --cartella=partita
    --porta=N        porta TCP (predefinita 5050)
    --cartella=PATH  cartella dei file (predefinita: sottocartella "partita")
    --senza-rete     solo file, niente TCP (nessun permesso del firewall)
    --seme=N         codice fisso (per le prove)
    --via            parte subito senza aspettare il tasto V
    --senza-tasti    non legge la tastiera (per le prove automatiche)
    --durata=SEC     si ferma da solo dopo SEC secondi (per le prove)
  Comandi anche da file: scrivere VIA oppure NUOVA dentro  <cartella>\comando.txt }

{$mode objfpc}{$H+}

uses
  {$ifdef unix}cthreads,{$endif}
  SysUtils, Classes, Crt, mm_logica, mm_file, mm_tcp;

var
  Tab: TMMTabella;
  FS: TMMFileServer;
  Srv: TMMTcpServerThread;
  porta: Word;
  cartella, fileIp, ultimoQuadro, quadro, cmd, t: String;
  senzaRete, senzaTasti, avviaVia: Boolean;
  durata: Integer;
  i, nuovi: Integer;
  seme: Int64;
  inizio, ultimoPoll: Double;
  fine: Boolean;
  ultimoRanking: String;
  exeDir: String;

function Opzione(const Nome: String; out Valore: String): Boolean;
var
  k: Integer;
begin
  Result := False;
  for k := 1 to ParamCount do
    if (ParamStr(k) = Nome) or (Copy(ParamStr(k), 1, Length(Nome) + 1) = Nome + '=') then
    begin
      Valore := Copy(ParamStr(k), Length(Nome) + 2, 500);
      Result := True;
      Exit;
    end;
end;

procedure CaricaIp;
var
  txt: String;
begin
  if MMLeggiTesto(fileIp, txt) then Tab.CaricaIpNomi(txt) else Tab.IpNomi.Clear;
end;

procedure NuovaPartita;
begin
  Tab.Blocca;
  try
    Tab.NuovaPartita(seme);     // seme = -1 -> casuale
    seme := -1;
  finally
    Tab.Sblocca;
  end;
  FS.Dimentica;
  FS.ScriviFile;
end;

procedure FaiVia;
begin
  Tab.Blocca;
  try
    Tab.Via;
  finally
    Tab.Sblocca;
  end;
  FS.ScriviFile;
end;

function Quadro_: String;
begin
  Tab.Blocca;
  try
    Result := 'MASTERMIND 2.0 - SERVER   [V] Via!  [N] Nuova partita  [R] ridisegna  [I] ip-nomi  [Q] esci' + LineEnding;
    if senzaRete then Result := Result + 'Rete: SPENTA (solo file)  '
    else if Srv.Pronto then Result := Result + 'Rete: in ascolto sulla porta ' + IntToStr(porta) + '  '
    else Result := Result + 'Rete: NON attiva ' + Srv.Errore + '  ';
    Result := Result + 'Cartella: ' + cartella + LineEnding + LineEnding +
      Tab.TestoClassifica + LineEnding + Tab.TestoPresenze;
  finally
    Tab.Sblocca;
  end;
end;

procedure Disegna(Forza: Boolean);
begin
  quadro := Quadro_;
  if Forza or (quadro <> ultimoQuadro) then
  begin
    ultimoQuadro := quadro;
    if not senzaTasti then ClrScr else WriteLn('------------------------------------------------');
    Write(quadro);
  end;
end;

begin
  Tab := TMMTabella.Create;
  exeDir := ExtractFilePath(ParamStr(0));
  porta := 5050;
  if Opzione('--porta', t) then porta := StrToIntDef(t, 5050);
  if not Opzione('--cartella', cartella) then cartella := exeDir + 'partita';
  fileIp := exeDir + 'ip-nomi.txt';
  if Opzione('--ipnomi', t) then fileIp := t;
  senzaRete := Opzione('--senza-rete', t);
  senzaTasti := Opzione('--senza-tasti', t);
  avviaVia := Opzione('--via', t);
  durata := 0;
  if Opzione('--durata', t) then durata := StrToIntDef(t, 0);
  seme := -1;
  if Opzione('--seme', t) then seme := StrToInt64Def(t, -1);

  FS := TMMFileServer.Create(Tab, cartella);
  CaricaIp;
  NuovaPartita;
  Srv := nil;
  if not senzaRete then
  begin
    Srv := TMMTcpServerThread.Create(Tab, porta);
    Sleep(300);
  end;
  if avviaVia then FaiVia;
  inizio := SecondiOra;
  ultimoPoll := 0;
  fine := False;
  ultimoQuadro := '';
  ultimoRanking := '';
  repeat
    // 1. tastiera
    if not senzaTasti then
      while KeyPressed do
        case UpCase(ReadKey) of
          'V': FaiVia;
          'N': begin NuovaPartita; ultimoQuadro := ''; end;
          'R': ultimoQuadro := '';
          'I': CaricaIp;
          'Q': fine := True;
        end;
    // 2. comando da file
    if MMLeggiTesto(IncludeTrailingPathDelimiter(cartella) + 'comando.txt', cmd) then
    begin
      DeleteFile(IncludeTrailingPathDelimiter(cartella) + 'comando.txt');
      cmd := UpperCase(Trim(cmd));
      if cmd = 'VIA' then FaiVia
      else if cmd = 'NUOVA' then NuovaPartita
      else if cmd = 'FINE' then fine := True;
    end;
    // 3. ogni 2 secondi rilegge i file dei ragazzi
    if SecondiOra - ultimoPoll >= 2 then
    begin
      ultimoPoll := SecondiOra;
      nuovi := FS.Poll;
      if nuovi > 0 then FS.ScriviFile;
    end;
    // 4. se la rete ha cambiato la classifica, riscrivo i file (cosi' chi usa i file la vede)
    Tab.Blocca;
    try
      t := Tab.TestoRanking;
    finally
      Tab.Sblocca;
    end;
    if t <> ultimoRanking then
    begin
      ultimoRanking := t;
      FS.ScriviFile;
    end;
    Disegna(False);
    Sleep(100);
    if (durata > 0) and (SecondiOra - inizio > durata) then fine := True;
  until fine;
  FS.ScriviFile;
  if Srv <> nil then
  begin
    Srv.Terminate;
    Srv.WaitFor;
    Srv.Free;
  end;
  FS.Free;
  Tab.Free;
end.
