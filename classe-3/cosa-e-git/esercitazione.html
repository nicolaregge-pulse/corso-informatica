Esercitazione: Cos'è Git · অনুশীলন: গিট কী?

Classe 3 · Informatica · si scrive in Google Documenti e si consegna su Google Classroom · bilingue IT / বাংলা

Obiettivo: scrivere un breve documento che spiega, con parole tue, cos'è Git.

Italiano

  1. Apri un documento nuovo: nel browser vai su docs.new e dai un titolo (es. "Cos'è Git — Nome Cognome").
  2. Spiega con parole tue: (a) cos'è Git; (b) cos'è un commit; (c) cos'è un repository; (d) la differenza tra Git e GitHub.
  3. Aggiungi un esempio pratico: perché Git è utile (es. tornare a una versione precedente, lavorare in gruppo senza sovrascriversi).
  4. (Facoltativo) Inserisci uno screenshot del tuo account o del tuo primo repository su GitHub.
  5. Consegna il documento su Classroom.

Nota: conta soprattutto saperlo spiegare a voce, con parole tue.

বাংলা

  1. একটি নতুন ডকুমেন্ট খোলো: ব্রাউজারে docs.new-এ যাও এবং একটি শিরোনাম দাও (যেমন "গিট কী — নাম ও পদবি")।
  2. নিজের ভাষায় ব্যাখ্যা করো: (ক) Git কী; (খ) commit কী; (গ) repository কী; (ঘ) Git ও GitHub-এর পার্থক্য।
  3. একটি বাস্তব উদাহরণ দাও: Git কেন উপকারী (যেমন আগের সংস্করণে ফিরে যাওয়া, একে অপরের কাজ না মুছে দলে কাজ করা)।
  4. (ঐচ্ছিক) তোমার GitHub অ্যাকাউন্ট বা প্রথম repository-এর একটি স্ক্রিনশট যোগ করো।
  5. ডকুমেন্টটি Classroom-এ জমা দাও।
