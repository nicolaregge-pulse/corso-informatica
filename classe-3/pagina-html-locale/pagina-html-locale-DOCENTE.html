Guida per il docente — Pagina HTML di presentazione (in locale)

Classe 3 · 3 ore · nessun account necessario · 30/09/2026

1. Obiettivo e perché funziona

  1. Ogni allievo crea una pagina web personale sul proprio PC (in locale): risultato visibile e "suo", senza dipendere da account GitHub.
  2. Si tocca con mano il legame codice → risultato: cambio il codice, salvo, aggiorno (F5), vedo la modifica.

2. Come condurla (3 ore)

  1. Ora 1 — la pagina base: spieghi cos'è una pagina web; alla lavagna/proiettore scrivi il codice del riquadro; tutti lo copiano nel Blocco note, mettono i loro dati e la aprono nel browser. Obiettivo: ognuno vede la sua pagina.
  2. Ora 2 — personalizzazione e colori (CSS): mostri dove sono i colori (dentro <style>); ognuno cambia lightblue e darkblue, aggiunge campi (es. classe, data di nascita). Demo live: cambi un colore, salvi, F5.
  3. Ora 3 — extra + consegna: chi vuole sposta il CSS in un file separato (vedi punto 4); poi tutti consegnano il file su Classroom e scrivono la riflessione (cosa non fatto/perché + cosa non capito).

3. Come si fa vedere la modifica (la parte "magica")

  1. Tieni aperte due finestre: Blocco note (il codice) e il browser (la pagina).
  2. Cambi una cosa nel Blocco note (un colore, il titolo) → File → Salva (o Ctrl+S) → nel browser premi F5 (aggiorna) → la modifica compare. Ripetilo 2-3 volte: capiscono subito il meccanismo.

4. Extra: il CSS in un file separato (per chi va veloce)

  1. Nel Blocco note apri un nuovo file, scrivi solo le righe di stile senza <style>, per esempio:
    body { background: lightblue; }   h1 { color: darkblue; }
  2. Salvalo (Tutti i file) come stile.css nella stessa cartella.
  3. Nel file HTML togli il blocco <style>...</style> e al suo posto scrivi, dentro <head>:
    <link rel="stylesheet" href="stile.css">
  4. Salvi entrambi e aggiorni: la pagina prende lo stile dal file esterno. Concetto: contenuto (HTML) separato dall'aspetto (CSS).

5. Errori comuni (e soluzione)

  1. Si salva come .txt: ricordare "Tutti i file" e nome che finisce in .html. Se è .txt: Salva con nome di nuovo.
  2. La pagina è "codice" e non colorata: di solito è salvata come .txt o manca un'estensione: risalva come .html.
  3. Accenti strani: tenere <meta charset="utf-8"> nel codice (già presente).
  4. Tag non chiuso (manca una </...>): far ricopiare la riga dal riquadro.

6. Differenziazione

  1. Chi fatica: basta la pagina base con i propri dati e un colore cambiato.
  2. Chi va veloce: aggiunge una foto (<img src="foto.jpg"> con una foto nella stessa cartella), più campi, il CSS separato; chi ha l'account GitHub può pubblicarla su Pages (passo facoltativo).
Privacy: è tutto in locale. Ricordare agli allievi che i dati non vanno pubblicati; il telefono può essere inventato. Se qualcuno pubblica su Pages, usare dati non sensibili.
Autorevolezza: non serve sapere l'HTML a memoria. Basta seguire questa guida e fare la demo live "cambio-salvo-F5": è quella che fa capire tutto.
