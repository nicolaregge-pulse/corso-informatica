Esercitazione — Sposta il CSS in un file separato

Classe 3 · Informatica · 30/09/2026 · dopo la pagina base · IT / বাংলা
ITALIANO — separa lo stile: dall'HTML a un file CSS
Finora HTML e stile stanno insieme in un solo file. Ora li separiamo: il testo resta nell'HTML, i colori/stile vanno in un file stile.css. Idea: HTML = contenuto, CSS = aspetto.
1) Trova il blocco stile
Nel tuo file HTML, dentro <head>, trova il blocco <style> ... </style>.
2) Crea il file stile.css
Apri un nuovo Blocco note e copia solo le regole (senza i tag <style> e </style>):
body { background: lightblue; font-family: Arial; text-align: center; }
h1 { color: darkblue; }
.scheda { background: white; padding: 20px; border-radius: 10px;
          display: inline-block; text-align: left; }
Salva: File → Salva con nome → Tutti i file, nome stile.css, nella stessa cartella di presentazione.html.
3) Collega il CSS all'HTML
Nel file HTML cancella tutto il blocco <style> ... </style> e al suo posto, dentro <head>, scrivi:
<link rel="stylesheet" href="stile.css">
4) Salva e guarda
Salva l'HTML e premi F5 nel browser: la pagina è identica, ma ora lo stile arriva dal file esterno.
5) Prova che funziona
Apri stile.css, cambia un colore (es. lightblue → pink), salva e premi F5: il colore cambia. È il CSS che comanda l'aspetto, da fuori.
Consegna: aggiorna il tuo Documento con: uno screenshot della pagina, il codice HTML, il codice di stile.css, e la riflessione (cosa non sono riuscito a fare/perché, cosa non ho capito).
Stessa cartella! stile.css e presentazione.html devono stare nella stessa cartella, altrimenti la pagina non trova lo stile.
বাংলা — স্টাইল আলাদা করো: HTML থেকে একটি CSS ফাইলে
এতক্ষণ HTML ও স্টাইল একই ফাইলে ছিল। এখন আলাদা করি: লেখা HTML-এ থাকবে, রং/স্টাইল যাবে stile.css ফাইলে। ধারণা: HTML = বিষয়বস্তু, CSS = চেহারা।
১) স্টাইল ব্লক খুঁজে বের করো
তোমার HTML ফাইলে <head>-এর ভেতরে <style> ... </style> ব্লকটি খোঁজো।
২) stile.css ফাইল বানাও
একটি নতুন Notepad খোলো এবং শুধু নিয়মগুলো কপি করো (<style> ও </style> ট্যাগ ছাড়া):
body { background: lightblue; font-family: Arial; text-align: center; }
h1 { color: darkblue; }
.scheda { background: white; padding: 20px; border-radius: 10px;
          display: inline-block; text-align: left; }
সেভ করো: File → Salva con nome → Tutti i file, নাম stile.css, presentazione.html-এর একই ফোল্ডারে।
৩) CSS-কে HTML-এর সাথে যুক্ত করো
HTML ফাইলে <style> ... </style> ব্লকটি পুরো মুছে দাও, তার জায়গায় <head>-এর ভেতরে লেখো:
<link rel="stylesheet" href="stile.css">
৪) সেভ করে দেখো
HTML সেভ করে F5 চাপো: পেজ একই থাকবে, কিন্তু স্টাইল এখন বাইরের ফাইল থেকে আসছে।
৫) কাজ করছে যাচাই করো
stile.css খুলে একটি রং বদলাও (lightblue → pink), সেভ করে F5: রং বদলাবে। বাইরে থেকে CSS-ই চেহারা নিয়ন্ত্রণ করে।
জমা দাও: তোমার Documento আপডেট করো: পেজের স্ক্রিনশট, HTML কোড, stile.css কোড, ও রিফ্লেকশন।
একই ফোল্ডার! stile.css ও presentazione.html অবশ্যই একই ফোল্ডারে রাখতে হবে, নাহলে পেজ স্টাইল খুঁজে পাবে না।
