Dispensa 6 — Lavoriamo come un'azienda

ডিসপেন্সা ৬ — চলো একটি কোম্পানির মতো কাজ করি
Classe 3 · Informatica · 08/10/2026 · il gioco della classe: fork, Pull Request, merge, versioni · IT / বাংলা
Cosa facciamo oggi: costruiamo tutti insieme un gioco per il telefono, come si fa nelle aziende di software. Il lavoro è diviso in pezzi: ognuno fa il suo, lo propone con una Pull Request, il prof lo unisce (merge) e alla fine esce una versione nuova del gioco, con dentro il lavoro di tutti.
আজ আমরা কী করব: সবাই মিলে ফোনের জন্য একটি খেলা বানাব, সফটওয়্যার কোম্পানির মতো। কাজটি টুকরো টুকরো ভাগ করা: প্রত্যেকে নিজের অংশ করে, Pull Request দিয়ে প্রস্তাব দেয়, শিক্ষক যোগ করেন (merge), আর শেষে সবার কাজ নিয়ে খেলার নতুন সংস্করণ বের হয়।

1. I ruoli, come in un'azienda

RuoloChiCosa fa
Product owneril profdecide cosa entra in ogni versione e fa il merge
শিক্ষক: কী যোগ হবে ঠিক করেন, merge করেন
Project manageruno per squadra, a turnotiene la lista dei lavori della squadra e apre la Pull Request di squadra
প্রতি দলে একজন, পালাক্রমে: কাজের তালিকা রাখে, দলের Pull Request খোলে
Sviluppatorituttifanno il proprio pezzo e lo propongono
সবাই: নিজের অংশ বানায় ও প্রস্তাব দেয়
Revisoreil controllo automatico + un compagnoguarda la modifica prima del merge
স্বয়ংক্রিয় পরীক্ষা + একজন সহপাঠী: merge-এর আগে দেখে

2. Il primo lavoro di tutti: il tuo mostro

RIQUADRO 11 — il tuo mostro (cambia i valori!)
{
  "nome": "Gnam Gnam",
  "colore": "#ff6fb1",
  "occhi": 3,
  "corna": 1,
  "bocca": 0,
  "velocita": 2,
  "frase": "Ti mangio il Wi-Fi!",
  "immagine": false
}
Il file si chiama come il tuo PC, sempre con due cifre: PC 7 → mostri/pc07.json, PC 14 → mostri/pc14.json. Sulla pagina della classe scegli il tuo PC: il nome del file è già pronto da copiare.
ফাইলের নাম তোমার PC-র নম্বরে, সবসময় দুই অঙ্কে: PC 7 → mostri/pc07.json। ক্লাসের পেজে তোমার PC বেছে নাও: ফাইলের নাম কপি করার জন্য তৈরি।
1Apri il progetto · প্রজেক্ট খোলো

Entra su github.com con il TUO account e apri https://github.com/nicolaregge-pulse/assalto-dei-mostri.

তোমার অ্যাকাউন্ট দিয়ে github.com-এ ঢোকো আর খোলো https://github.com/nicolaregge-pulse/assalto-dei-mostri।

2Crea il file · ফাইল বানাও

Sopra l'elenco dei file: bottone grigio Add file → Create new file. GitHub ti dice che serve una copia tua: premi il bottone verde Fork this repository (crea la tua copia).

ফাইলের তালিকার উপরে: ধূসর বোতাম Add file → Create new file। GitHub বলবে তোমার নিজের কপি লাগবে: সবুজ বোতাম Fork this repository চাপো।

3Nome e contenuto · নাম ও বিষয়বস্তু

Nel campo del nome incolla il TUO nome di file (es. mostri/pc14.json). Nel riquadro grande incolla il RIQUADRO 11.

নামের ঘরে তোমার ফাইলের নাম পেস্ট করো (যেমন mostri/pc14.json)। বড় বাক্সে বাক্স ১১ পেস্ট করো।

4Fallo tuo · নিজের মতো করো

Cambia nome, colore, occhi (1-3), corna (0-1), bocca (0-2), velocità (1-3) e la frase che grida. Lascia le virgolette e le virgole come sono.

নাম, রং, চোখ (১-৩), শিং (০-১), মুখ (০-২), গতি (১-৩) আর তার চিৎকারের বাক্য বদলাও। উদ্ধৃতি চিহ্ন আর কমা যেমন আছে রাখো।

5Proponi la modifica · পরিবর্তন প্রস্তাব করো

Bottone verde Commit changes... → nella finestra bottone verde Propose changes (proponi). Poi bottone verde Create pull request, e ancora Create pull request.

সবুজ বোতাম Commit changes... → জানালায় সবুজ বোতাম Propose changes। তারপর সবুজ বোতাম Create pull request, আবার Create pull request।

6Il controllo automatico · স্বয়ংক্রিয় পরীক্ষা

Aspetta un minuto nella pagina della tua Pull Request: compare una spunta verde (tutto a posto) o una X rossa. Con la X, clic su Details: c'è scritto cosa sistemare (di solito una virgola). Sistema il file nella tua copia: la Pull Request si aggiorna da sola.

তোমার Pull Request-এর পেজে এক মিনিট অপেক্ষা করো: সবুজ টিক (সব ঠিক) অথবা লাল X আসবে। X হলে Details-এ ক্লিক করো: কী ঠিক করতে হবে লেখা আছে (সাধারণত একটি কমা)। তোমার কপিতে ফাইল ঠিক করো: Pull Request নিজেই আপডেট হবে।

7Il merge · Merge

Il prof guarda la tua Pull Request e la unisce al gioco. Quando è viola con scritto Merged: FATTO! Il tuo mostro è nel gioco. Apri https://nicolaregge-pulse.github.io/assalto-dei-mostri/ e cercalo nell'elenco dei mostri della classe.

শিক্ষক তোমার Pull Request দেখে খেলায় যোগ করবেন। বেগুনি হয়ে Merged লেখা এলে: হয়ে গেছে! তোমার দানব খেলায় আছে। খোলো https://nicolaregge-pulse.github.io/assalto-dei-mostri/ আর ক্লাসের দানবদের তালিকায় খুঁজে দেখো।

3. Il lavoro di squadra

SquadraFileCosa cambia
REGOLEregole.jsonquanti colpi regge il vetro, quanto in fretta sparano i mostri, i punti
ভাঙার আগে কাচ কতটা গুলি সহ্য করে, দানবরা কত দ্রুত গুলি করে, পয়েন্ট
GRAFICAgrafica.jsoni colori della città: cielo, luna, palazzi, finestre, strada
শহরের রং: আকাশ, চাঁদ, দালান, জানালা, রাস্তা
TESTItesti.jsonil titolo, le frasi di fine partita, i messaggi (anche nella tua lingua)
শিরোনাম, খেলা শেষের বাক্য, বার্তা (তোমার ভাষাতেও)
SUONIsuoni.jsonil volume e le note della musica di vittoria
ভলিউম আর জয়ের সুরের নোট
8Squadra · দল

Il project manager apre la Issue della squadra (scheda Issues del progetto) e scrive nei commenti chi fa cosa.

প্রজেক্ট ম্যানেজার দলের Issue খোলে (Issues ট্যাব) আর মন্তব্যে কে কী করবে লেখে।

9Squadra · দল

La squadra decide su carta i valori nuovi (colori, frasi, regole).

দল কাগজে নতুন মান ঠিক করে (রং, বাক্য, নিয়ম)।

10Squadra · দল

Il project manager cambia il file della squadra con la matita e fa la Pull Request, come per il mostro. Negli autori scrive solo i numeri dei PC.

প্রজেক্ট ম্যানেজার পেনসিল দিয়ে দলের ফাইল বদলায় আর Pull Request করে, দানবের মতোই। autori-তে শুধু PC নম্বর লেখে।

11Squadra · দল

Un compagno di un'altra squadra fa la revisione: nella Pull Request, scheda Files changed, guarda le modifiche e scrive un commento.

অন্য দলের একজন রিভিউ করে: Pull Request-এ Files changed ট্যাবে পরিবর্তন দেখে মন্তব্য লেখে।

Il conflitto: se due persone cambiano la stessa riga dello stesso file, GitHub non sa quale tenere. Non è un disastro: succede in tutte le aziende. Il prof ve lo fa vedere alla lavagna e lo risolve con voi.
কনফ্লিক্ট: দুজন একই ফাইলের একই লাইন বদলালে GitHub জানে না কোনটি রাখবে। এটা বিপদ নয়: সব কোম্পানিতে হয়। শিক্ষক বোর্ডে দেখিয়ে তোমাদের সাথে সমাধান করবেন।

4. La versione nuova e il grafico

12La release · রিলিজ

Quando i lavori sono uniti, il prof pubblica la release v1.1 (i mostri della classe) e poi la v1.2 (le squadre). Il numero in basso a destra nel gioco cambia.

কাজগুলো যোগ হলে শিক্ষক v1.1 রিলিজ (ক্লাসের দানব) আর পরে v1.2 (দলগুলোর কাজ) প্রকাশ করেন। খেলার নিচে ডানদিকের নম্বর বদলায়।

13Il grafico delle versioni · সংস্করণের গ্রাফ

Nel progetto: scheda Insights → a sinistra Network. Vedi tutte le copie (fork), i commit e i merge: è la storia del lavoro di tutti.

প্রজেক্টে: Insights ট্যাব → বাঁদিকে Network। সব কপি (fork), commit আর merge দেখবে: সবার কাজের ইতিহাস।

Carta e penna: disegna il grafico delle versioni del gioco: la linea principale (main) da v1.0 a v1.2, la tua copia che parte, il tuo commit, la freccia del merge che torna nella linea principale.
কাগজ-কলম: খেলার সংস্করণের গ্রাফ আঁকো: মূল লাইন (main) v1.0 থেকে v1.2, তোমার কপি যেখান থেকে শুরু, তোমার commit, আর merge-এর তীর যা মূল লাইনে ফেরে।
