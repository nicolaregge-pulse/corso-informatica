Dispensa 2 — Pubblica il tuo primo sito su GitHub

ডিসপেন্সা ২ — GitHub-এ তোমার প্রথম সাইট প্রকাশ করো
Classe 3 · Informatica · 05/10/2026 · GitHub Pages, tutto dal browser · IT / বাংলা
Cosa ottieni: un indirizzo internet vero, come https://tuonome.github.io/mio-sito/, che chiunque può aprire, anche sul telefono. È il tuo primo sito pubblico.
তুমি পাবে: একটি সত্যিকারের ইন্টারনেট ঠিকানা, যেমন https://tuonome.github.io/mio-sito/, যা যে কেউ খুলতে পারবে, ফোনেও। এটা তোমার প্রথম পাবলিক সাইট।
Prima di iniziare ti serve: 1) la cartella mio-sito con index.html e style.css (Dispensa 1); 2) il tuo account GitHub (nome utente e password).
Parole nuove: repository = la cartella del progetto su GitHub · commit = salvare una versione · upload = caricare · GitHub Pages = il servizio gratis che trasforma il repository in un sito.
শুরু করার আগে লাগবে: ১) index.html ও style.css সহ mio-sito ফোল্ডার (ডিসপেন্সা ১); ২) তোমার GitHub অ্যাকাউন্ট (ইউজারনেম ও পাসওয়ার্ড)।
নতুন শব্দ: repository = GitHub-এ প্রজেক্টের ফোল্ডার · commit = একটি সংস্করণ সেভ করা · upload = আপলোড করা · GitHub Pages = ফ্রি সেবা যা repository-কে সাইট বানায়।
Controllo privacy PRIMA di caricare: apri index.html e verifica: niente cognome, telefono, email, indirizzo, foto del viso. Quello che carichi lo vede il mondo intero.
আপলোডের আগে গোপনীয়তা যাচাই: index.html খুলে দেখো: পদবি, ফোন, ইমেল, ঠিকানা, মুখের ছবি নেই। যা আপলোড করবে, সারা পৃথিবী দেখবে।
Se la pagina di GitHub è tradotta (in italiano o nella tua lingua) i nomi dei bottoni cambiano: cerca il bottone per posizione e colore, come nei disegni (il cerchio rosso indica dove cliccare).
GitHub-এর পেজ অনুবাদ করা থাকলে (ইতালিয়ান বা তোমার ভাষায়) বোতামের নাম বদলে যায়: ছবির মতো জায়গা আর রং দেখে বোতাম খোঁজো (লাল দাগ দেখায় কোথায় ক্লিক করতে হবে)।

1. Crea il repository

1Entra su GitHub · GitHub-এ ঢোকো

Apri il browser e vai all'indirizzo github.com. In alto a destra Sign in (Accedi): scrivi nome utente e password.

ব্রাউজার খুলে এই ঠিকানায় যাও (ঠিক এভাবে লেখো): github.com। উপরে ডানদিকে Sign in (ঢোকো): ইউজারনেম ও পাসওয়ার্ড লেখো।

2Nuovo repository · নতুন repository

In alto a destra clic sul + → New repository (Nuovo repository).

উপরে ডানদিকে + চিহ্নে ক্লিক করো → New repository (নতুন repository)।

3Dai il nome e crea · নাম দাও ও বানাও

In Repository name scrivi mio-sito. Lascia Public (Pubblico). Metti Add README su On (o spunta la casella). In basso a destra clic sul bottone verde Create repository.

Repository name-এ লেখো mio-sito। Public (পাবলিক) রেখে দাও। Add README On করো (বা বাক্সে টিক দাও)। নিচে ডানদিকে সবুজ বোতাম Create repository-এ ক্লিক করো।

2. Carica i tuoi due file

4Add file → Upload files · Add file → Upload files

Nella pagina del repository clic su Add file (bottone grigio, a sinistra del bottone verde Code) → Upload files (Carica file).

repository-র পেজে Add file-এ ক্লিক করো (ধূসর বোতাম, সবুজ Code বোতামের বাঁদিকে) → Upload files (ফাইল আপলোড)।

5Trascina i file · ফাইল টেনে আনো

Apri Esplora file → Desktop → mio-sito. Seleziona i due file (Ctrl + A) e trascinali nel riquadro tratteggiato della pagina. (Oppure clic su choose your files e scegli i due file.)

Esplora file (File Explorer) খোলো → Desktop → mio-sito। দুটি ফাইল বেছে নাও (Ctrl + A) এবং পেজের ডট-দাগের বাক্সে টেনে আনো। (অথবা choose your files-এ ক্লিক করে দুটি ফাইল বেছে নাও।)

6Salva su GitHub: il commit · GitHub-এ সেভ: commit

Controlla che si vedano index.html e style.css. In basso clic sul bottone verde Commit changes. Hai fatto un commit: hai salvato una versione, come abbiamo visto con Git.

দেখো index.html ও style.css দেখা যাচ্ছে কিনা। নিচে সবুজ বোতাম Commit changes-এ ক্লিক করো। তুমি একটি commit করলে: একটি সংস্করণ সেভ করলে, যেমন Git-এ দেখেছি।

3. Accendi il sito (GitHub Pages)

7Settings · Settings

In alto, nella fila di schede del repository, clic sull'ultima a destra: Settings (Impostazioni, con l'ingranaggio ⚙).

উপরে repository-র ট্যাবের সারিতে একদম ডানদিকের ট্যাবে ক্লিক করো: Settings (সেটিংস, গিয়ার ⚙ চিহ্ন)।

<> CodeIssuesPull requestsActionsProjectsSecurity⚙ Settings ←
8Pages · Pages

Nel menu a sinistra scendi un po' e clic su Pages.

বাঁদিকের মেনুতে একটু নিচে নেমে Pages-এ ক্লিক করো।

9Scegli main e salva · main বেছে সেভ করো

Sotto Build and deployment: Source = Deploy from a branch. In Branch clic su None e scegli main; accanto lascia / (root). Clic su Save (Salva).

Build and deployment-এর নিচে: Source = Deploy from a branch। Branch-এ None-এ ক্লিক করে main বেছে নাও; পাশে / (root) রেখে দাও। Save (সেভ)-এ ক্লিক করো।

10Aspetta 1-2 minuti · ১-২ মিনিট অপেক্ষা করো

Premi F5 ogni tanto. In alto compare Your site is live at ... (Il tuo sito è online) con il bottone Visit site. Cliccalo: FATTO! Il tuo sito è su internet.

মাঝে মাঝে F5 চাপো। উপরে আসবে Your site is live at ... (তোমার সাইট অনলাইন) আর Visit site বোতাম। ক্লিক করো: হয়ে গেছে! তোমার সাইট ইন্টারনেটে।

Your site is live at https://tuonome.github.io/mio-sito/   Visit site
11Mostralo · দেখাও

L'indirizzo è https://TUONOME.github.io/mio-sito/ (TUONOME = il tuo nome utente GitHub). Aprilo sul telefono e fallo vedere a un compagno. L'hai fatto tu!

ঠিকানা হলো https://TUONOME.github.io/mio-sito/ (TUONOME = তোমার GitHub ইউজারনেম)। ফোনে খোলো আর একজন সহপাঠীকে দেখাও। তুমি নিজে বানিয়েছ!

4. Se qualcosa non va

ProblemaSoluzione
Vedo 404 / There isn't a GitHub Pages site here
404 দেখাচ্ছে
Aspetta ancora 2 minuti e premi F5. Controlla che il file si chiami proprio index.html (minuscolo) e che in Pages ci sia main salvato.
আরও ২ মিনিট অপেক্ষা করে F5 চাপো। দেখো ফাইলের নাম ঠিক index.html (ছোট হাতের) এবং Pages-এ main সেভ আছে কিনা।
Il sito si vede ma senza colori
সাইট দেখা যায় কিন্তু রং নেই
Nel repository manca style.css, o ha un nome diverso. Ricaricalo con Add file → Upload files.
repository-তে style.css নেই, বা নাম আলাদা। Add file → Upload files দিয়ে আবার আপলোড করো।
Non trovo un bottone
বোতাম খুঁজে পাচ্ছি না
Guarda il disegno: posizione e colore. Poi alza la mano: ti aiuto io.
ছবি দেখো: জায়গা আর রং। তারপর হাত তোলো: আমি সাহায্য করব।
Vuoi cambiare il sito dopo? Nel repository clic sul file (es. style.css) → la matita ✎ in alto a destra → cambia → bottone verde Commit changes. Dopo un minuto, F5 sul sito: è aggiornato. Ogni modifica è una nuova versione.
পরে সাইট বদলাতে চাও? repository-তে ফাইলে ক্লিক করো (যেমন style.css) → উপরে ডানদিকে পেনসিল ✎ → বদলাও → সবুজ বোতাম Commit changes। এক মিনিট পরে সাইটে F5: আপডেট হয়ে গেছে। প্রতিটি পরিবর্তন একটি নতুন সংস্করণ।
Carta e penna: scrivi sul quaderno il tuo indirizzo github.io e lo schema: PC (cartella mio-sito) → upload + commit → GitHub (repository) → Pages → sito pubblico.
কাগজ-কলম: খাতায় তোমার github.io ঠিকানা আর এই ছক লেখো: PC (mio-sito ফোল্ডার) → upload + commit → GitHub (repository) → Pages → পাবলিক সাইট।
