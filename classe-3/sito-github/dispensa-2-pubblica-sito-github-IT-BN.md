# Dispensa 2 — Pubblica il tuo primo sito su GitHub

ডিসপেন্সা ২ — GitHub-এ তোমার প্রথম সাইট প্রকাশ করো

Classe 3 · Informatica · 05/10/2026 · GitHub Pages, tutto dal browser · IT / বাংলা

**Cosa ottieni:** un **indirizzo internet vero** , come https://tuonome.github.io/mio-sito/, che chiunque può aprire, **anche sul telefono**. È il tuo primo sito pubblico.

**তুমি পাবে:** একটি **সত্যিকারের ইন্টারনেট ঠিকানা** , যেমন https://tuonome.github.io/mio-sito/, যা যে কেউ খুলতে পারবে, **ফোনেও** । এটা তোমার প্রথম পাবলিক সাইট।

**Prima di iniziare ti serve:** 1) la cartella **mio-sito** con **index.html** e **style.css** (Dispensa 1); 2) il tuo account **GitHub** (nome utente e password).  
**Parole nuove:** **repository** = la cartella del progetto su GitHub · **commit** = salvare una versione · **upload** = caricare · **GitHub Pages** = il servizio gratis che trasforma il repository in un sito.

**শুরু করার আগে লাগবে:** ১) **index.html** ও **style.css** সহ **mio-sito** ফোল্ডার (ডিসপেন্সা ১); ২) তোমার **GitHub** অ্যাকাউন্ট (ইউজারনেম ও পাসওয়ার্ড)।  
**নতুন শব্দ:** **repository** = GitHub-এ প্রজেক্টের ফোল্ডার · **commit** = একটি সংস্করণ সেভ করা · **upload** = আপলোড করা · **GitHub Pages** = ফ্রি সেবা যা repository-কে সাইট বানায়।

**Controllo privacy PRIMA di caricare:** apri index.html e verifica: **niente cognome, telefono, email, indirizzo, foto del viso**. Quello che carichi lo vede il mondo intero.

**আপলোডের আগে গোপনীয়তা যাচাই:** index.html খুলে দেখো: **পদবি, ফোন, ইমেল, ঠিকানা, মুখের ছবি নেই** । যা আপলোড করবে, সারা পৃথিবী দেখবে।

**Se la pagina di GitHub è tradotta** (in italiano o nella tua lingua) i nomi dei bottoni cambiano: cerca il bottone per **posizione e colore** , come nei disegni (il cerchio **rosso** indica dove cliccare).

**GitHub-এর পেজ অনুবাদ করা থাকলে** (ইতালিয়ান বা তোমার ভাষায়) বোতামের নাম বদলে যায়: ছবির মতো **জায়গা আর রং** দেখে বোতাম খোঁজো (**লাল** দাগ দেখায় কোথায় ক্লিক করতে হবে)।

Problema| Soluzione

Vedo **404** / **There isn't a GitHub Pages site here****404** দেখাচ্ছে| Aspetta ancora 2 minuti e premi F5. Controlla che il file si chiami proprio **index.html** (minuscolo) e che in Pages ci sia **main** salvato.আরও ২ মিনিট অপেক্ষা করে F5 চাপো। দেখো ফাইলের নাম ঠিক **index.html** (ছোট হাতের) এবং Pages-এ **main** সেভ আছে কিনা।  
Il sito si vede ma **senza colori** সাইট দেখা যায় কিন্তু **রং নেই**|  Nel repository manca **style.css** , o ha un nome diverso. Ricaricalo con **Add file -> Upload files**.repository-তে **style.css** নেই, বা নাম আলাদা। **Add file -> Upload files** দিয়ে আবার আপলোড করো।  
Non trovo un bottoneবোতাম খুঁজে পাচ্ছি না| Guarda il disegno: posizione e colore. Poi alza la mano: ti aiuto io.ছবি দেখো: জায়গা আর রং। তারপর হাত তোলো: আমি সাহায্য করব।  
  
**Vuoi cambiare il sito dopo?** Nel repository clic sul file (es. **style.css**) -> la **matita** ✎ in alto a destra -> cambia -> bottone verde **Commit changes**. Dopo un minuto, F5 sul sito: è aggiornato. Ogni modifica è una **nuova versione**.

**পরে সাইট বদলাতে চাও?** repository-তে ফাইলে ক্লিক করো (যেমন **style.css**) -> উপরে ডানদিকে **পেনসিল** ✎ -> বদলাও -> সবুজ বোতাম **Commit changes** । এক মিনিট পরে সাইটে F5: আপডেট হয়ে গেছে। প্রতিটি পরিবর্তন একটি **নতুন সংস্করণ** ।
