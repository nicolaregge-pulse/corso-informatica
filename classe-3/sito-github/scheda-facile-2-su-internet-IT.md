# Metti la tua pagina su internet in 7 passi

Classe 3 · scheda FACILE · 05/10/2026 · italiano

**Alla fine:** la tua pagina ha un **indirizzo vero** e la apri anche sul **telefono**. Cerca i bottoni con il **cerchio rosso** nei disegni.

1Entra su GitHub

Vai su github.com -> in alto a destra **Sign in** -> nome utente e password.

2Nuovo repository

In alto a destra clic sul **+** -> **New repository**.

GitHub\+ ▾

New repository

3Dai il nome

Nome: mio-sito. Lascia **Public**. **Add README** su **On**. Bottone verde **Create repository**.

Repository name: mio-sito  
◉ Public   Add README: **On**  

Create repository

4Carica i 2 file

**Add file** -> **Upload files**. Trascina **index.html** e **style.css** dalla cartella mio-sito. Bottone verde **Commit changes**.

Add file ▾ Code

index.html   style.css

Commit changes

5Settings e Pages

In alto a destra **Settings** (ingranaggio) -> a sinistra **Pages** -> Branch: **main** -> **Save**.

⚙ Settings -> **Pages** -> Branch: main ▾ Save

6Aspetta 2 minuti

Premi F5. In alto compare **Your site is live** e il bottone **Visit site** : cliccalo!

Your site is live at **https://tuonome.github.io/mio-sito/** Visit site

7Mostralo!

**FATTO! Sei su internet.** Apri l'indirizzo sul telefono e fallo vedere a un compagno.

**Prima di caricare:** nella pagina solo nome o soprannome. Niente cognome, telefono, email.
