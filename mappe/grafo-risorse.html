Flussi principali (come si collegano le risorse)
  1. Autore→Ragazzi: Nicola prepara nel repo (main) → pubblica Release → i ragazzi ricevono la versione stabile.
  2. Giochi online: repo docs/ → GitHub Pages → gioco giocabile da un link.
  1. Compiti: Classroom (allega Moduli/Documenti) → i ragazzi consegnano su Drive → Nicola scarica lo ZIP → valuta in area privata.
  2. Regione: DIDAweb (presenze/argomenti) → export Excel → aggiorna Allegato A nel repo → docx per la Regione.
  1. AI dei ragazzi: i materiali .md → NotebookLM / Gemini → l'AI spiega e traduce nella loro lingua.
  2. Repo allievi: Classroom 50 crea 1 repository privato per allievo nell'organizzazione.
