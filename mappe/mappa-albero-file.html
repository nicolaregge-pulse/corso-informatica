Come si ricostruisce
1. I file "sciolti" hanno il percorso nel nome (con "__").
2. `strumenti/nome-albero.py espandi` → ricrea l'albero.
3. Su Windows: "__" diventa la cartella "\".
Legenda: in grassetto = cartelle; il numero a destra = quanti file contiene. _build/ = generatori PDF (non materiale).
