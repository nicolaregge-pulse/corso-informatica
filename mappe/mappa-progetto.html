1 · Missione e metodo
  1. Chi: ragazzi spesso in svantaggio/migratori; qui "cosa fatta bene", rispetto e fiducia.
  2. Motore: Vinci subito · Fallo tuo · Mostralo. Errore = zero vergogna.
  3. Prova del nove: saperlo spiegare a voce con parole proprie.
  4. Tassativo: carta e penna in ogni lezione.
  5. Stella polare: 00-STATO-DEL-CORSO (fonte di verità).
2 · Struttura didattica
  1. Imbuto 4 anni: 1ª basi larghe → 4ª specializzazione.
  2. Documenti: Mappa, Menu, Griglia (competenze), Piano ore.
  3. Fili rossi: glossario, quaderno, IA, Git.
  4. Programmazione: Lazarus → poi Godot (assaggio 1ª/2ª, sviluppo 3ª-4ª).
  5. 3ª novità: Database/SQL, Web, reti/cablaggio.
3 · Materiali creati
  1. Classe 1: regole, hardware (parti/componenti/costruisci PC), versioning, GitHub, utenze&password, negozio online.
  2. Quiz: Google Moduli via script (trilingue, autocorrezione).
  3. Libro di testo Classe 1 + libri personali per allievo.
  4. Godot: manuale + eserciziario + giochi.
  5. Terza: contenitore "Comunicazione digitale".
4 · Gestione della classe
  1. Un Excel per classe: Allievi · Registro voti · Assenze · Allegato A.
  2. Voti in centesimi (/100): sempre due letture, oggettivo + commisurato.
  3. Regole voto: presente-non-consegna = 30; assente = —.
  4. Domande al volo: 70 OK / 50 KO.
  5. Firma ore entro le 14:05 (monte ore Regione).
5 · Regione — Allegato A (PFP)
  1. Preventivo per competenza → si evidenzia in giallo ciò che si farà.
  2. Durante l'anno: fatto → togli il giallo; non fatto → cancella.
  3. Fonte svolto: export Excel del registro elettronico.
  4. Fine anno: programma svolto per competenza → docx ufficiale.
  5. Sorgenti in repo: MIE-PARTI, allegato-a-*, PROGRAMMA-PREVENTIVO.
6 · Git e versioning
  1. main = area autore; Release vX.Y = versione stabile per i ragazzi.
  2. Due fasi: 1ª esercizi separati (1 commit) → 3ª-4ª branch/PR/release.
  3. Repo allievi: organizzazione + 1 repo privato ciascuno (Classroom 50).
  4. Tutto visuale: browser / GitHub Desktop, mai la riga di comando.
  5. Ogni documento: MD (sorgente) + PDF (consegnabile) versionati.
7 · Sbobinature e quaderni
  1. Sbobinatura della lezione → teoria, argomenti, note dei ragazzi.
  2. Conservazione integrale (verbatim) + versione lavorata.
  3. Quaderno personale: ogni ragazzo ha il SUO libro che cresce.
  4. Alimenta: libro di testo, argomenti svolti, "Mostralo".
8 · Regole trasversali
  1. Privacy: nomi/certificazioni/assenze dei minori = solo scratchpad, MAI su Git.
  2. Trilingue (IT/AR/ZH) per ogni materiale degli allievi.
  3. Nomi file: DATA_Descrizione_Chi_Lingua_vX.Y (Chi = Classe-N-PerTutti o Classe-N-Cognome-Nome).
  4. Formattazione: liste numerate, niente emoji, box colorati.
