Git: salvare la storia del tuo lavoro

Classe 2 · Informatica · 25/09/2026 · v1.0 · teoria + compito · Italiano

Oggi impari 4 parole e 1 idea. L'idea: il computer può ricordare tutte le versioni del tuo lavoro, come i salvataggi di un videogioco.
Carta e penna: mentre leggi, copia sul quaderno il disegno dei salvataggi (pagina 1) e le 4 parole (pagina 2).

1. Il problema

Hai mai visto file così?

Dopo un po' non sai più quale è quello giusto. È un gran disordine.

2. La soluzione: Git

Git è un programma che salva la storia del tuo lavoro. Ogni volta che salvi, Git si ricorda com'era. Se sbagli, puoi tornare indietro.

È come nei videogiochi: salvi prima del boss. Se perdi, riparti dal salvataggio.


Ogni pallino è un salvataggio. Puoi tornare a qualsiasi pallino.

3. Le 4 parole di Git

repositoryla cartella del progetto, con tutta la sua storia
commitun salvataggio (come una foto del lavoro)
branchuna strada a parte, per provare senza rovinare
mergeunire la strada a parte con quella principale

4. Git e GitHub: non sono la stessa cosa

  1. Git = il programma che salva la storia.
  2. GitHub = il sito internet dove metti i tuoi progetti, per non perderli e lavorare con altri. L'indirizzo è github.com

5. I numeri delle versioni

Ogni versione ha un numero. Si parte da v1.0.

  1. Piccola modifica (correggo un errore): cambia il numero dopo il punto. v1.0 → v1.1
  2. Grande cambiamento (rifaccio tutto): cambia il numero prima del punto e dopo si rimette 0. v1.1 → v2.0
