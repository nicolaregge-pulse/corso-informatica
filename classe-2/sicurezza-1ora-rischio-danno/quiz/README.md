# Quiz — Sicurezza 1ª ora: "Concetti di rischio e danno" (Classe 2)

**Versione 1.0** — 01/10/2026

Quiz su Google Moduli (20 domande × 5 punti = 100, punteggio automatico, Nome e
Cognome obbligatori) sulla 1ª ora di sicurezza del sito Piamarta "Formazione
sicurezza": salute, pericolo, danno, rischio, prevenzione, protezione, gerarchia
delle misure, valutazione (P×D), infortunio/incidente, piramide 1-29-300.

Da usare in 6ª ora, DOPO videolezione + slide.

## 1. File
1. `crea-quiz-sicurezza-1ora-2inf.gs` — script Apps Script che crea il Modulo in 1 clic.

3. In "Esecuzioni" compaiono i link del Modulo.
